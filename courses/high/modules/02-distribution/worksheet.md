## 5. 표준편차를 자로 쓰기 — z-점수

"평균에서 **표준편차 몇 개만큼** 떨어졌나"를 재 보자. 1절의 도시
B(평균 12, 표준편차 5)에서 1일의 5°C가 얼마나 튀는 값인지, 두
단계로 잰다:

1. **빼기** — 평균에서 떨어진 거리: 5 − 12 = **−7°C**
2. **나누기** — 그 거리를 표준편차라는 자로 다시 재기:
   −7 ÷ 5 = **−1.4** → "평균보다 표준편차 **1.4개**만큼 아래"

거리 ÷ 보폭 = 걸음 수와 같은 구조다. 나누는 순간 °C라는 단위가
사라지므로, 기온이든 시험 점수든 어떤 데이터에서도 통하는 '튀는
정도' 점수가 된다. 표준편차를 자로 쓴 **표준 점수** — 통계에서 쓰는
기호를 따라 **z-점수**라고 부른다.

같은 계산을 1,096일 전체에 한꺼번에 하는 코드 — 읽는 법:

> `z = (t - t.mean()) / t.std()`
> = t의 1,096개 값 **각각**에서 / 평균을 빼고 / 표준편차로 나눈
> 1,096개의 z-점수 (한 줄이 1,096번의 계산을 대신한다)

```python
t = df["temp_avg"]
z = (t - t.mean()) / t.std()
z.loc["2024-01-23"]
```

**Q7.** 3년 중 가장 추웠던 2024-01-23(-12.3°C)의 z-점수는 얼마인가?
문장을 완성하자: "이 날은 평균보다 표준편차 ___개만큼 낮았다."

z: ______ → 표준편차 ______개

이제 z의 절댓값이 2를 넘는 날을 전부 골라내자. 읽는 법:

> `z[abs(z) > 2]`
> = z 가운데 / **절댓값(abs)이 2보다 큰** 값만 골라 달라
> (대괄호 안에 조건을 쓰면, 조건이 참인 행만 남는다)

```python
z[abs(z) > 2]
```

## 6. 오타 실험 — 잣대가 망가질 때

마지막 날(2026-07-31)의 28.1을 소수점을 빠뜨린 **281**로 잘못
입력했다고 하자:

```python
broken = t.copy()
broken.loc["2026-07-31"] = 281
```

- `copy()` — 복사본을 만든다. 원본은 그대로 두고 복사본으로
  실험한다.
- `loc`는 읽기만이 아니라 **쓰기**에도 쓴다 — 그 행을 찾아 새 값을
  넣는다.

```python
broken.mean()
```

```python
broken.median()
```

```python
broken.std()
```
