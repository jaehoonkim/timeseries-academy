## 2. 계절성 프로필 — 달마다의 보통

import pandas as pd

url = "https://raw.githubusercontent.com/jaehoonkim/timeseries-academy/main/data/seoul-temp-daily.csv"

1절의 "요일 평균"을 기온에서는 "달마다의 평균"으로 만든다 — 읽는 법:

> `t.groupby(t.index.month).mean()`
> = t의 1,096일을 / **월 번호(1~12)가 같은 날끼리 묶어**(groupby) /
> 묶음마다 **평균**을 구하라
> (`t.index.month`는 날짜 인덱스에서 월 번호만 꺼낸 것)

```python
profile = t.groupby(t.index.month).mean()
profile
```

```python
profile.plot(label="월별 보통", legend=True)
```

12개 점으로 그린 이 곡선이 서울 기온의 **계절성 프로필** — "몇 월엔
보통 몇 도"의 목록이다.

## 3. 편차 — 보통에서 얼마나 벗어났나

이제 1,096일 각각을 저마다의 "보통"과 비교한다. 어떤 날의 보통이란
**그 날짜가 속한 달의 프로필 값**이다 — 8월 10일이면 프로필의 8월
값(26.7°C), 1월 21일이면 1월 값(-3.2°C). 1절에서 금요일의 90명을
"금요일의 보통 73명"과 비교했듯, 같은 비교를 1,096일 전부에 하는
것이다. 그러려면 12줄짜리 profile을 1,096일 각자의 자리에
돌려놓아야 한다 — 읽는 법:

> `t.groupby(t.index.month).transform("mean")`
> = 같은 달끼리 묶어 평균을 내되 / 요약하지 말고 그 평균을
> **1,096일 원래 자리마다 되돌려 놓아라**(transform)
> (`mean()`은 12줄 요약, `transform("mean")`은 1,096줄 그대로 —
> 1월의 모든 날에 1월 평균이, 8월의 모든 날에 8월 평균이 적힌다)

```python
monthly = t.groupby(t.index.month).transform("mean")
a = t - monthly
a.plot(label="편차", legend=True)
```

`a`가 1절의 편차다: 그날 기온이 그 달의 보통보다 몇 도 높거나
낮았는가.

## 4. 분해 — 관측 = 추세 + 계절 + 잔차

3절의 "보통"은 3년 내내 같다고 가정했다. 그런데 H3 Q8에서 우리는
연평균이 **오르는 중**임을 봤다 — 보통 자체가 천천히 움직인다.
그래서 관측을 세 몫으로 쪼갠다:

> **관측 = 추세 + 계절 + 잔차**
> 추세: 천천히 움직이는 배경 수준 / 계절: 해마다 반복되는 물결 /
> 잔차: 둘로 설명되지 않은 나머지

**추세**는 H3에서 이미 만들었다 — 365일 창은 계절을 지운다(H3 Q7).
단, 이번엔 창을 중심에 놓는다:

```python
trend = t.rolling(window=365, center=True).mean()
trend.plot(label="추세", legend=True)
```

**계절**은 3절의 프로필을 다시 쓰되, 추세 몫을 먼저 걷어낸
나머지에서 계산한다 — 같은 양을 두 몫에 이중으로 세지 않기 위해서다.
**잔차**는 남은 전부다:

```python
detr = t - trend
seasonal = detr.groupby(detr.index.month).transform("mean")
resid = t - trend - seasonal
```

세 몫을 차례로 그려 보자 (원본과 함께 넉 장):

```python
t.plot(label="관측", legend=True)
```

```python
trend.plot(label="추세", legend=True)
```

```python
seasonal.plot(label="계절", legend=True)
```

```python
resid.plot(label="잔차", legend=True)
```
