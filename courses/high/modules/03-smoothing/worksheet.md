## 2. 파이썬으로 — rolling

데이터를 불러온다:

```python
import pandas as pd

url = "https://raw.githubusercontent.com/jaehoonkim/timeseries-academy/main/data/seoul-temp-daily.csv"
df = pd.read_csv(url, parse_dates=["date"], index_col="date")
t = df["temp_avg"]
```

1절의 손 계산을 1,096일 전체에 하는 코드 — 읽는 법:

> `t.rolling(window=7).mean()`
> = t 위에 **7일짜리 창**을 얹어 / 하루씩 **밀며(rolling)** /
> 창 안의 **평균**을 구하라

```python
ma7 = t.rolling(window=7).mean()
ma7.head(10)
```

## 4. 뒤늦은 창 — 후행과 중심

`rolling(window=7)`의 창은 "**지난** 7일"이다(후행). 창을 그날의 앞뒤
3일씩으로 바꿀 수도 있다(중심):

> `t.rolling(window=7, center=True).mean()`
> = 7일 창을 밀되 / 결과를 창의 **한가운데 날**에 적어라
> (그날 기준 앞 3일 + 그날 + 뒤 3일의 평균)

2026년 1월의 한파(H2에서 z-점수로 잡았던 그 사흘)를 확대해서 두
방식을 비교한다:

```python
ma7c = t.rolling(window=7, center=True).mean()
t.loc["2026-01"].plot(label="원본", legend=True)
ma7.loc["2026-01"].plot(label="후행 7일", legend=True)
ma7c.loc["2026-01"].plot(label="중심 7일", legend=True)
```

## 5. 지수평활 — 부드럽게 잊기

rolling 창의 무게는 이상하다: 창 안의 7일은 전부 똑같이 중요하고,
8일째가 되는 순간 **갑자기 0**이 된다. 태풍이 창을 빠져나가는 날
선이 툭 꺾이는 이유다. 대안: **최근일수록 무겁게, 과거로 갈수록
무게를 일정 비율로 줄이기.** 무게가 지수적으로(등비수열처럼)
줄어들어 **지수평활**이라고 부른다.

> `t.ewm(alpha=0.3).mean()`
> = 오늘에 무게 0.3을 주고 / 과거로 하루 갈 때마다 무게를
> ×0.7씩 줄인 / 전체의 가중평균
> (ewm = exponentially weighted mean, α는 "오늘을 얼마나 믿을지")

α = 0.3일 때의 무게: 오늘 0.3, 어제 0.21, 그제 0.147, … —
갑자기 끊기는 날이 없다.

```python
e = t.ewm(alpha=0.3).mean()
t.loc["2026-01"].plot(label="원본", legend=True)
ma7.loc["2026-01"].plot(label="7일 이동평균", legend=True)
e.loc["2026-01"].plot(label="지수평활", legend=True)
```
