## 예상 질문 / 오개념

- **`NameError: name 'df' is not defined`** — 최다 빈출. 위의
  import/read_csv 셀부터 순서대로 실행. 런타임이 초기화된 경우도
  같은 증상 (런타임 → 모두 실행).
- **`SyntaxError`** — 따옴표·괄호 짝. 에러 메시지의 화살표(^)가
  위치를 가리킨다.
- **"parse_dates 안 하면 어떻게 돼요?"** — 날짜가 글자로 남아
  `df.loc["2026-01"]` 같은 기간 조회가 안 되고, 그래프 가로축도
  어색해진다. 한 번 빼고 실행해 보여주면 가장 빠르다 (practice에서
  강의자가 미리 겪어 본다).
- **"`df.loc["2026-01"]`은 어떻게 한 달이 통째로 나와요?"** — 날짜
  인덱스의 부분 문자열 기능. "2026-01"로 시작하는 모든 날짜와
  매칭된다. "2026"만 쓰면 1년 치가 나온다.
- **"코드를 외워야 해요?"** — 아니. 매 모듈 코드는 다시 제공된다.
  읽고 고쳐 쓸 수 있으면 충분하다.
- 오개념 주의: **"그래프가 오르면 계속 오른다"** — 짧은 구간의
  방향을 전체 추세로 일반화하는 것. 3년 그래프에서 어떤 2주는
  오르막이지만 전체는 물결이다.

## 강의자용 심화

- `parse_dates`가 만드는 타입은 `datetime64[ns]` — 내부적으로 기준
  시각부터의 나노초 정수다. 날짜 연산(간격, 비교, 리샘플링)이 정수
  연산이라 빠르다. 엑셀·시트의 날짜 일련번호와 같은 발상.
- 시계열 vs 횡단면(cross-section) 데이터의 구분: Q1의 (가)가
  횡단면, (나)가 시계열. 시계열의 결정적 성질은 **관측 간 독립이
  아니라는 것**(자기상관) — 오늘 기온은 어제와 강하게 상관된다.
  H5에서 이 상관을 정식으로 재고, 랜덤 셔플 기반의 통계 직관이
  왜 시계열에서 깨지는지(train/test 시간 분할, H7)로 이어진다.
- `df.plot()`이 세 열을 자동으로 겹쳐 그리는 이유: pandas의 plot은
  숫자 열 전부를 각각의 선으로 그린다. matplotlib이 뒤에서 동작하며,
  H2부터는 `kind="hist"`, `kind="box"` 등 종류를 바꿔 쓴다.
- Colab 운영: 무료 티어는 유휴 시 런타임이 끊긴다(변수 소멸, 코드
  보존) → "런타임 → 모두 실행"으로 복구. 노트북은 학생 Drive에 자동
  저장된다. 제출을 받는다면 "런타임 다시 시작 → 모두 실행"이
  통과되는 상태로 받을 것.
