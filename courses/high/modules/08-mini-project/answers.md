# H8. 미니 프로젝트 — 예시 프로젝트 결과 및 발표 예시

학생 프로젝트에는 정답이 없다 — 평가는 teacher.md의 루브릭으로
한다. 이 문서는 practice의 **예시 프로젝트(서울 일교차)** 정답과
시범 발표다. 모든 수치는 현재 CSV(2023-08-01 시작 1,096일) 기준.

## 예시 프로젝트 결과

- **탐색(H1·H2)**: 평균 8.9°C, 표준편차 3.1°C. 기온의 매끈한
  물결과 달리 그래프가 심하게 들쭉날쭉하다. |z| > 3은 네 번 —
  2024-04-02(3.05), 2024-04-14(3.21), 2025-03-26(3.33),
  2025-04-12(**4.10**, 일교차 21.7°C로 전체 최대) — **전부 봄**.
  최대의 날은 맑고 건조한 봄날(낮에 데워지고 밤에 식는다), 최소
  1.3°C(2024-09-12)는 종일 흐리고 비 온 날의 전형.
- **리듬(H4)**: 달의 보통(훈련 2년) — **4월 11.6°C 최대, 7·8월
  7.0°C 최소**. 맑고 건조한 봄 vs 흐리고 습한 장마철. 요일의
  보통은 8.5에서 9.2 사이로 평평 — 죽은 재료(기온과 같은 결론).
  (M8 예시의 7월 6.8과 다른 이유: M8은 3년 전체, 여기는 훈련
  2년만 — H7 Q6과 같은 사연.)
- **관성(H5)**: 시차 1 자기상관 **0.44** — 기온(0.98)의 절반
  이하. 시차 7은 0.20. "naive는 벽이 아닐 것"이라는 예감의 근거.
- **벤치마크 순위표(H6)** — 분할은 H6·H7과 동일(훈련 730일,
  시험 365일):

  | 선수 | MAE (°C) | RMSE (°C) |
  |---|---|---|
  | 계절 naive(작년) | 3.09 | 3.87 |
  | naive(어제) | 2.44 | 3.12 |
  | 훈련 평균 | 2.44 | 3.00 |
  | 7일 이동평균 | 2.09 | 2.66 |
  | 회귀(어제) | 2.13 | 2.67 |
  | **회귀(어제+달의보통)** | **1.97** | **2.51** |

  기온의 순위표가 뒤집혔다: naive가 훈련 평균과 동급으로
  내려앉고 **7일 평균이 naive를 이긴다**(잡음이 크면 평균이
  유리 — M8과 같은 결론을 고교 도구로 재확인).
- **도전자(H7)**: 회귀(어제) 계수 **0.43** = 시차 1 자기상관
  0.44(H7 심화 공식의 재현), 절편 5.09. 회귀(어제+달의보통)의
  배합은 **어제 28% + 달의 보통 72%, 절편 0.0** — 기온(80:20)과
  정반대. 관성이 약하니 회귀가 어제에 대한 믿음을 줄이고 보통에
  몫을 준 것.
- **어디서 벌었나**: 월별 MAE에서 회귀(어제+달의보통)는 열두 달
  중 열한 달에서 naive보다 오차를 줄였다. 크게 번 달은
  **6월**(3.10 → 2.02)·**2월**(2.89 → 2.20)·**12월**(2.51 →
  1.88), 유일하게 손해 본 달은 **10월**(2.16 → 2.24). 기온
  때(겨울에만 벌고 3월에 손해)와 달리 전면전 승리 — 벽이 낮은
  데이터라서다.

## 시범 발표 예시 (5장)

1. **질문**: "서울의 일교차, naive는 벽일까?"
2. **데이터**: 서울 일별 기온 3년(1,096일, 결측 0), 일교차 =
   최고 − 최저로 직접 계산.
3. **발견 셋**: ① 그래프가 들쭉날쭉하고 시차 1 자기상관이
   0.44 — 기온(0.98)과 성격이 다른 데이터. ② 달의 보통은 4월
   최대·한여름 최소로 굴곡이 뚜렷(살아 있는 재료), 요일은
   평평(죽은 재료). ③ 튀는 날 네 번이 전부 봄 — 맑고 건조한
   봄날이 일교차의 챔피언.
4. **승부**: naive MAE 2.44는 벽이 아니었다(7일 평균 2.09에도
   진다). 회귀(어제+달의보통)가 1.97로 우승 — 배합은 어제 28% +
   보통 72%로 기온과 정반대였고, 열두 달 중 열한 달에서 벌었다.
5. **한계와 다음 재료**: 자기상관 0.44가 말하듯 어제로는 절반도
   설명이 안 된다 — 일교차의 원인(구름·습도·바람)을 담은 재료가
   있어야 더 내려간다. 3년으로는 "4월 최대"의 확신에도 한계.

## 수업 전 최종 확인

- 백업 데이터 CSV들이 오늘 기준으로도 정상 동작하는지(공공
  포털은 형식이 종종 바뀐다) 직전에 한 번 더 실행 확인.
- 예시 프로젝트의 수치는 현재 CSV 기준 — 데이터를 갱신하면 이
  문서와 practice의 수치를 함께 갱신할 것.
- 발표일에 각 팀 노트북이 "런타임 다시 시작 → 모두 실행"으로
  깨끗하게 통과되는지 미리 점검시키면 발표 중 사고가 준다.
