# H8. 미니 프로젝트 — 강의자 노트

- 목표: 각자 고른 시계열 데이터로 질문 → 수집 → 탐색 → 리듬·관성
  → 벤치마크 → 회귀 도전 → 발표를 완주한다. 새 도구는 없다 —
  H1~H7의 총동원.
- 평가의 두 축(H7 예고 그대로): **"내 데이터의 '달의 보통'은
  무엇인가"**(주기 찾기)와 **"naive를 이겼는가"**(벤치마크 규율).
  둘째 축은 "이겼다/졌다"가 아니라 규율을 지켰는지가 핵심이다.
- 준비물: 학생당 Colab + **백업 데이터 2~3종**(아래). 팀은 1~2인
  권장.
- 시간: **2회차 권장** — 1회차(75분) 킥오프 + 작업, 2회차(75분)
  마무리 + 발표. 1회로 압축하면 활동지 1~2번(질문·데이터 준비)을
  사전 숙제로 낼 것.

## 사전 준비 (강의자)

- **백업 데이터**: 수집에서 막히는 팀이 반드시 나온다(경험상
  1/3). 즉시 건넬 CSV를 준비해 둘 것. 추천:
  1. 이 저장소 CSV 그대로 + **일교차 질문** — practice의 예시
     프로젝트. 파일 준비가 0초이고, 기온과 정반대 결말이라
     "배운 결론이 데이터 따라 뒤집힌다"를 보여 주기 최적.
  2. 기상포털의 **다른 도시 기온** (서울과 비교 질문 가능)
  3. 서울 **미세먼지** 일평균 (계절 리듬 뚜렷, 사건도 있음)
- practice의 예시 프로젝트(일교차)를 직접 완주해 둘 것 — 순회
  지도 중 모든 단계의 "막혔을 때 보여줄 예시"가 된다.
- 발표 순서 추첨 방법과 타이머를 정해 둔다.

## 수업 흐름 (1회차)

### 0:00–0:10 킥오프 — 도구 상자 회고 (활동지 도입·1번)

> 오늘은 새로 배우는 게 없다. 지금까지 배운 걸 다 쓴다 — 보고,
> 분포로 재고, 펴고, 쪼개고, 닮음을 재고, 규칙과 심판을 세우고,
> 도전자를 만들었지. 도구 상자는 꽉 찼다. 이제 **네 데이터**다.

활동지 1번(질문 정하기)을 10분 안에 끝내게 한다 — 여기서 오래
끌수록 분석 시간이 사라진다. 질문이 안 나오는 팀에는 후보 표에서
거꾸로 고르게 한다("미세먼지 → 그럼 질문은?"). "예감" 칸(달의
보통 자리에 무엇이 올까)은 꼭 쓰게 할 것 — H7 Q15의 전이가 여기서
일어난다.

### 0:10–0:30 데이터 준비 (활동지 2번)

가장 많이 막히는 구간. 순회하며 즉시 해결한다:

- **CSV 한글이 외계 문자** → `encoding="cp949"`. 공공데이터 최다
  빈출.
- **그래프 한글이 □** → koreanize 셀을 건너뛴 것. 실행 후 그래프
  셀 재실행.
- **날짜 파싱 실패** → "2026.08.17"·"20260817" 형태면
  `df.index = pd.to_datetime(df.index, format="%Y.%m.%d")`처럼
  형식을 지정한다(그 자리에서 같이 만들어 준다).
- **엑셀 파일** → `pd.read_excel` 또는 CSV로 다시 저장.
- **천 단위 쉼표("1,234")** → `pd.read_csv(..., thousands=",")`.
- **기간 부족** → 질문을 데이터에 맞게 줄인다("연 리듬" → "요일
  리듬"). 두 번 반복 원칙(H4) + 홀드아웃 몫(90행)으로 판정.
- 15분이 지나도 데이터가 없는 팀 → 주저 없이 **백업 데이터**
  투입. 수집이 아니라 분석·발표가 이 모듈의 본체다.

### 0:30–1:10 분석 + 승부 (활동지 3~6번)

순회 지도 포인트 — H8에서 특히 지킬 것 셋:

- **프로필 반칙 감시**: 프로필을 전체 데이터로 계산하는 실수가
  가장 잦다. "profile 만든 줄에 train이 들어 있나?"를 순회 중
  물어 줄 것(H7 5절의 규칙).
- **재료 조합 반칙 감시**: 시험 성적을 보면서 재료를 넣었다 뺐다
  하는 팀 — H7 Q14 그대로 "고르는 건 좋다, 어디 성적으로
  고르느냐가 문제"로 교정.
- **만점 = 반칙 신호**: 시험 MAE가 0에 가까우면 칭찬보다 먼저
  새는 재료(오늘 값이 재료에 들어감)를 함께 찾는다 — H7
  practice의 실험을 실전에서 만나는 순간이다.

그 외:

- 각 팀 그래프에 **"튀는 값 있네 — 무슨 일이 있었어?"**를 물어
  주면 H2의 문화(지우기 전에 원인)가 살아난다.
- **주별 데이터** 팀: `shift(1)`은 1행 = 1주다 — naive가 "지난주와
  같다"가 된다는 걸 짚어 줄 것. 창·시차의 단위는 "행"이다.
- 자기상관이 낮아 naive가 약한 팀: 실망이 아니라 기회다 — 기온과
  반대 결말이라 발표가 더 재미있어진다(예시 프로젝트가 정확히
  그 경우).
- 프로필이 평평한 팀: 없다는 발견도 발견(H7 Q12의 죽은 재료).
  다른 주기를 하나 더 시험하게 한다.

### 1:10–1:15 1회차 마무리

발표 틀(활동지 7번)을 소개하고 그래프 다섯 장을 준비해 오게
한다. "그래프 한 장 = 발견 한 개"만 반복 강조.

## 수업 흐름 (2회차)

- 0:00–0:20 마무리 작업 + 팀 내 리허설 1회.
- 0:20–1:05 발표 — 팀당 5분 + 질문 2분. **청중 규칙**: 발표마다
  질문 하나씩 준비. 좋은 질문의 예를 미리 준다: "그 튀는 값은
  무슨 일이었나요?"(H2), "프로필은 훈련 구간으로만 계산했나요?"
  (H6·H7), "naive는 이겨 봤나요 — 어디서 벌었나요?"(H7).
- 1:05–1:15 수료식 — 활동지 8번 "나의 세 문장"을 몇 명 발표.

> 여덟 번 동안 한 걸 한 문장으로: **시간이 담긴 데이터를 보고,
> 재고, 펴고, 쪼개고, 닮음을 재서 — 규칙 위에서 예측하고, 얼마나
> 틀렸는지 쟀다.** 이게 시계열 분석의 전부이고, 나머지는 더 좋은
> 재료와 더 좋은 배합일 뿐이다.

## 평가 루브릭 (발표)

| 항목 | 잘함 | 보통 | 아쉬움 |
|---|---|---|---|
| 질문 | 한 문장, 데이터로 답 가능 | 있으나 모호 | 질문 없이 데이터만 |
| 데이터 기술 | 출처·기간·행 수·결측 모두 | 일부 | 없음 |
| 리듬·관성 | 프로필 굴곡과 자기상관으로 데이터 성격 설명 | 프로필만 | 둘 다 없음 |
| 이상치 | 원인을 조사/추측해 설명 | 있다고만 언급 | 못 봄 / 말없이 삭제 |
| 벤치마크 규율 | naive 채점 + 훈련만으로 프로필·조합 + 홀드아웃 준수 | 일부 준수 | naive 없음 / 반칙 |
| 승부 읽기 | 배합 문장 + 어디서 벌었는지까지 | 성적 숫자만 | 예측 없음 |
| 한계 | 스스로 한계와 다음 재료 제시 | 물으면 답함 | 인식 없음 |

점수화보다 피드백 언어로 — "프로필을 훈련으로만 계산했네, H6를
제대로 썼다"처럼 모듈 이름으로 칭찬하면 배운 것이 연결된다.

## 예상 질문 / 오개념

- **"naive를 못 이겼어요"** — 정상 결말 중 하나다(기온이 그랬다,
  H6·H7). 먼저 자기상관을 본다: 0.9 이상이면 원래 벽이 높은
  데이터다. 그다음 "큰 오차는 깎았나"(RMSE·구간별)를 본다 —
  못 이겼어도 규율을 지킨 분석이면 루브릭에서 만점이다.
- **"자기상관이 낮은데 왜 회귀는 이겨요?"** — naive는 어제를
  100% 믿는 배합 고정 선수인데, 자기상관이 낮으면 그 믿음이
  과하다. 회귀는 믿음(계수)을 데이터에 맞게 줄이고 남는 몫을
  보통에 준다 — 예시 프로젝트(어제 28% + 보통 72%)가 이 답의
  실물이다.
- **"계절성이 안 나와요"** — 없음도 발견(H7 Q12). 단, 기간이
  주기의 2배가 안 되면 "이 데이터로는 판단 불가"가 정직한
  결론이다.
- **"예측이 너무 안 맞아요"** — 오차의 크기는 방법이 아니라
  데이터의 성질이 먼저 정한다. 검색량·미세먼지는 기온보다 원래
  어렵다. naive 대비 나아졌는지만 보면 된다.
- **"결측이 너무 많아요"** — 왜 비었는지부터. 주말마다 비는
  데이터(주가 등)는 결측이 아니라 "원래 없는 날" — 있는 날만으로
  분석한다.
- 오개념 주의: **"발표는 잘된 것만"** — 안 나온 리듬, naive에 진
  성적, 판단 불가도 정직하게 말하는 것이 이 과정의 태도다.
  루브릭의 "한계" 항목이 그 자리다.

## 강의자용 심화 — 이 다음은?

과정을 이어가고 싶은 학생을 위한 지도(H7 심화의 연장):

- **재료 발명의 계속**: 변화량(어제 − 그제), 최근 7일 표준편차,
  계절 사인 곡선 — H7 심화의 "1.5도 아래" 길. 재료 설계가 곧
  특징 공학(feature engineering)이라는 이름의 정식 분야다.
- **ARIMA·지수평활 모형들**: naive와 회귀의 정식 후속. 이 과정을
  마친 학생은 "naive를 이기는 게 목표"라는 관점을 이미 갖고 있어
  입문서의 절반을 건너뛴 셈이다.
- **데이터 대회**: 데이콘·캐글의 시계열 과제는 이 파이프라인
  그대로에 재료와 모형만 좋아진 것 — 도전해 볼 만하다.
