## 4. 리듬을 잰다 (H4·H5)

여기서 잰 두 가지가 뒤에서 승부를 좌우한다 — 리듬은 6절 도전자의
**재료**가 되고, 관성은 5절 naive 벽의 **높이를 예언**한다.

**리듬(프로필)** — 후보 주기마다 프로필을 만들어 **굴곡**을 본다.
재료의 정보량은 프로필의 굴곡이다(H7): 굴곡이 뚜렷하면 살아 있는
재료, 평평하면 죽은 재료다.

```python
v.groupby(v.index.month).mean().round(1)      # 달의 보통
v.groupby(v.index.dayofweek).mean().round(1)  # 요일의 보통 (0=월요일)
```

**관성(자기상관)** — 어제와 오늘이 얼마나 닮았나(H5):

```python
v.autocorr(1)
```

기온은 이 값이 0.98이라 naive가 벽이었다(H5·H6). 내 데이터가
그보다 훨씬 작다면 이번 승부는 기온과 다르게 흘러갈 것이다 —
예감을 적어 두고 5절에서 확인하자.

## 5. 규칙과 심판을 세운다 (H6)

분할선을 정한다 — 뒤쪽 1/3이 시험이다. 심판은 MAE·RMSE 둘 다.
그리고 도전자보다 먼저 **naive부터** 채점한다: 이 성적이 넘어야
할 벽의 높이다.

```python
data = pd.DataFrame({"어제": v.shift(1), "오늘": v}).dropna()
train = data[:"분할날짜"]
test = data["분할다음날":]

e_naive = test["오늘"] - test["어제"]
e_naive.abs().mean(), (e_naive**2).mean() ** 0.5
```

## 6. 도전자를 만든다 (H7)

특징 테이블을 만든다: 어제 + 4절에서 살아 있던 프로필. 단
**프로필은 훈련 구간에서만** 계산한다(시험 구간을 미리 보면
반칙 — H6·H7의 그 규칙).

```python
train_v = v[:"분할날짜"]
profile = train_v.groupby(train_v.index.month).mean()  # 내 주기에 맞게
key = pd.Series(v.index.month, index=v.index)          # 주기가 요일이면 dayofweek

data2 = pd.DataFrame({"어제": v.shift(1),
                      "보통": key.map(profile),
                      "오늘": v}).dropna()
train2 = data2[:"분할날짜"]
test2 = data2["분할다음날":]
```

```python
from sklearn.linear_model import LinearRegression

model = LinearRegression()
model.fit(train2[["어제", "보통"]], train2["오늘"])
model.coef_, model.intercept_
```

```python
pred = pd.Series(model.predict(test2[["어제", "보통"]]), index=test2.index)
e = test2["오늘"] - pred
e.abs().mean(), (e**2).mean() ** 0.5
```

- 배합을 문장으로 읽는다(H7 Q7) — 기온의 "어제 80% + 보통 20%"와
  같은가, 뒤집혔는가? 배합은 데이터가 정한다.
- **어디서 벌었는지** — 어느 구간에서 naive보다 오차를 줄였는지 —
  월별(또는 내 주기별)로 쪼개 본다(H7 6절).
- 재료 실험을 한 가지 이상 한다: 그제(`v.shift(2)`), 다른 프로필,
  변화량 등. 단 **조합 선택은 훈련 구간의 성적으로**(H7 Q14).
  시험 성적이 갑자기 만점에 가까워지면 기뻐하지 말고 **새는
  재료부터 의심**하자(H7 practice: 만점 = 반칙 신호).

## 7. 발표 — 5분 다섯 장

그래프 한 장 = 발견 한 개. 다섯 장이면 충분하다.

1. **내 질문** — 한 문장.
2. **데이터 소개** — 출처, 기간, 행 수, 결측 처리.
3. **발견 셋** — 각각 그래프 한 장과 함께. 리듬(프로필)과
   자기상관은 꼭 넣자 — 4절이 이 데이터의 성격 소개다.
4. **승부** — naive의 벽(높이와 이유) → 도전자의 성적 → 어디서
   벌었나. 정직하게: "이겼다" 한마디보다 "**어디서 얼마나
   깎았다**"가 이 과정의 문장이다. 못 이겼어도 그 이유(자기상관,
   죽은 재료)를 설명하면 훌륭한 발표다.
5. **한계와 다음 재료** — 전환점(급변)은 맞혔나? 못 맞혔다면
   어떤 **원인 재료**가 필요할까(H7 마지막 문단 — 기상청이
   기압·바람을 보는 이유).
