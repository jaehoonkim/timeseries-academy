  선수)과 달리 이번엔 회귀가 새는 재료를 알아서 배합에 넣기

  반칙 여부는 별개(H6에서 세운 문장)를 회귀에서도 확인하되, 위의
  두 실험이 "재료가 늘면 샐 구멍도 는다"의 실체임을 함께 봐 둘 것.

## 2. 추가 실습 — 학생보다 한 발 더 (약 25분)

1. **그제 추가 — 관성이라는 재료**: 전환점 공략의 첫 실마리를
   본다.

   ```python
   data5 = pd.DataFrame({"어제": t.shift(1), "그제": t.shift(2),
                         "달의보통": month.map(profile), "오늘": t}).dropna()
   train5 = data5[:"2025-07-31"]; test5 = data5["2025-08-01":]
   model5 = LinearRegression()
   model5.fit(train5[["어제", "그제", "달의보통"]], train5["오늘"])
   model5.coef_.round(2)
   ```

   성적 **1.56 / 2.08** — 오늘의 우승자(1.59 / 2.13)보다 좋다.
   계수는 어제 **0.99**, 그제 **-0.24**, 보통 0.25 — 그제의
   **음수** 계수가 핵심이다. 0.75×어제 + 0.24×(어제 − 그제)로
   묶어 읽으면 "(어제 − 그제) = 기온의 진행 방향"을 회귀가
   재료로 발명한 것: 내리막이던 기온은 계속 내리막(관성). 겨울
   성적도 12월 2.60, 2월 2.09로 더 깎인다. 단 2026-02-06의
   오차는 여전히 -8.1 — 관성 재료도 급락의 **첫날**은 못 맞힌다.
2. **회귀의 최악의 날**: 우승 모형(어제+달의보통)의 오차로
   `e2.abs().nlargest(3)` — 2026-02-06 **8.0도**, 2026-01-11
   **7.4도**, 2026-01-15 **6.8도**. 앞의 둘은 H6에서 본 naive의
   급락 전환점이고, 1/15는 전날 -5.3°C에서 당일 +2.1°C로 뛴
   **급등** 전환점이다 — 실패는 방향과 무관하게 전환점에 몰린다.

3. **RMSE/MAE 비율**: naive 1.38 → 회귀 **1.34**. "가끔 크게
   틀리는" 스타일은 그대로이되 정도가 줄었다 — 큰 오차를 깎았다는
   본문의 결론을 비율로도 확인.

4. **훈련 성적 vs 시험 성적**: 우승 모형의 훈련 구간 성적은
   1.50 / 2.09, 시험은 1.59 / 2.13 — 자기가 배운 시험지라 훈련이
   당연히 조금 좋다. 재료 2개짜리 모형이라 차이가 작지만, 재료가
   늘수록 이 간격이 벌어진다(H8에서 학생 모형이 재료를 쌓기
   시작하면 이 간격부터 볼 것).
