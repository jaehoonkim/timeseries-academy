## 3. lag plot — 1,095쌍의 어제와 오늘

1절에서 손으로 만든 "(어제, 오늘) 짝"을 pandas로 전 구간에 만든다.
도구는 shift — 읽는 법:

> `t.shift(1)`
> = t의 모든 값을 **하루씩 뒤로 밀어라**(shift)
> — 그러면 각 날짜 자리에 "어제의 값"이 와 있다
> (첫날 자리는 어제가 없으므로 NaN — H3의 NaN과 같은 정직함)

```python
pair = pd.DataFrame({"어제": t.shift(1), "오늘": t})

```

```python
pair.plot.scatter(x="어제", y="오늘", s=2)
```

1절의 모눈에 7점을 찍었다면, 이 그림은 1,095쌍을 찍은 것이다.
이렇게 "k일 전 vs 오늘"을 흩뿌린 그림을 **lag plot**이라 부른다
— **시차**(lag)는 며칠 밀었는지를 뜻한다.

## 4. 계절의 착시 — 0.98은 누구 덕인가

Q5에서 얻은 값 0.98은 놀랍도록 크다. 하지만 절반은 **계절의
공로**다 — 여름날의 어제는 어차피 여름날이다. 8월의 아무 이틀을
골라도, 이웃한 날이 아니어도 서로 닮는다.

그 공로는 3절 그림에서 눈에 보인다:

- 오른쪽 위 덩어리는 전부 **여름날의 짝**이다 — 어제도 오늘도
  27도 근처.
- 왼쪽 아래 덩어리는 전부 **겨울날의 짝**이다 — 둘 다 영하 근처.
- 저 긴 대각선은 계절이 1년에 걸쳐 점 구름을 영하 10도에서
  30도까지 끌고 다니며 늘어놓은 **배치**다 — 어제가 오늘을 말해
  줘서 생긴 줄이 아니다.

그래서 진짜 궁금한 것은 이것이다: **계절을 빼고도** 어제가
오늘을 말해 주는가? 계절을 뺀 시계열은 이미 있다 — 2절에서 만든
편차 a(그날 기온에서 그 달의 보통을 뺀 것)다. 3절의 lag plot을
t 대신 a로 다시 그린다:

```python
pair_a = pd.DataFrame({"어제": a.shift(1), "오늘": a})
pair_a.plot.scatter(x="어제", y="오늘", s=2)
```

이제 모든 날이 **자기 달의 보통을 0으로 삼아** 다시 찍힌다 —
여름날도 겨울날도 같은 원점 주위로 포개지고, 계절이 점들을 끌고
다니던 힘은 사라졌다. 그런데도 구름이 여전히 기울어 있다면,
그것은 순수한 "어제 → 오늘"의 힘이다.

상관은 이번엔 표를 거치지 않고 바로 구한다 — 시리즈와 그 하루 민
복사본을 직접 짝지어도 같은 계산이다:

```python
a.corr(a.shift(1))
```

## 5. 기억은 며칠 가나 — ACF

어제와는 0.75만큼 닮았다. 그럼 그제와는? 사흘 전과는? shift(2),
shift(3), …을 일일이 쓰는 대신 줄임말이 있다 — 읽는 법:

> `a.autocorr(k)`
> = `a.corr(a.shift(k))`의 줄임말 — **k일 전과의 자기상관**
> (k에 1, 2, 3, …을 넣어 가며 "기억의 세기"를 잴 수 있다)

시차 1부터 30까지의 자기상관을 한 번에 모아 그린다:

```python
lags = range(1, 31)
acf_a = pd.Series([a.autocorr(k) for k in lags], index=lags)
acf_a.plot(label="편차의 자기상관", legend=True)
```

(대괄호 안은 "k를 1부터 30까지 바꿔 가며 `a.autocorr(k)`를 모아
담아라"는 뜻이다.)

방금 만든 것이 제목의 **ACF**(autocorrelation function)다. 새
계산이 아니다 — 4절의 0.75가 "시차 1과의 자기상관" 하나였다면,
같은 질문을 시차 2, 3, …에도 던져 답을 시차 순서로 늘어놓은
것이다. 시차를 넣으면 자기상관이 나오는 대응이라서
**함수**(function)라 부르고, 가로축 시차·세로축 자기상관의
곡선으로 그린다.

이 곡선을 읽는 법: 각 점은 "**k일 전을 알면 오늘을 얼마나 말할
수 있나**"다 — Q2에서 손으로 세운 질문을 시차별로 반복한 것.
어제(0.75)는 오늘을 많이 말해 주고, 며칠 전은 조금만, 0 근처까지
내려간 시차의 과거는 아무것도 말해 주지 못한다 — 그만큼 먼
과거를 시계열이 **잊은** 것이다. 그래서 곡선이 0에 닿는 시차가
곧 기억의 길이다.
