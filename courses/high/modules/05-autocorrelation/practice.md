## 2. 추가 실습 — 학생보다 한 발 더 (약 20분)

1. **부호 일치율**: 워밍업의 "음수 다음엔 음수" 세기를 전 구간으로
   확장한다.

   ```python
   ((a > 0) == (a.shift(1) > 0)).mean()
   ```

   약 **0.79** — 하루의 편차 부호가 다음 날 유지될 확률이 8할이다.
   1절 손 계산(6/6)의 전 구간 버전이고, 자기상관 0.75를 "확률의
   말"로 옮긴 값이라 토론에서 쓰기 좋다.

2. **셔플 실험**: 편차의 값들을 무작위로 섞어 순서를 부수고 다시
   재 본다.

   ```python
   a.sample(frac=1, random_state=0, ignore_index=True).autocorr(1)
   ```

   약 **0.0**. 값의 분포는 그대로인데 순서만 부쉈더니 자기상관이
   사라졌다 — **자기상관은 값이 아니라 순서의 성질**이다. H2의
   히스토그램(순서를 버리는 도구)과 오늘의 ACF(순서를 읽는 도구)가
   정확히 반대편에 서 있음을 보여 주는 실험.

3. **잔차로도 재 보기**: H4의 분해를 다시 수행해 잔차의 자기상관을
   확인한다.

   ```python
   trend = t.rolling(window=365, center=True).mean()
   detr = t - trend
   seasonal = detr.groupby(detr.index.month).transform("mean")
   resid = t - trend - seasonal
   resid.autocorr(1)
   ```

   약 **0.73** — 편차의 0.75와 거의 같다. 추세까지 걷어내도 뭉침은
   남는다: 뭉침은 분해가 놓친 잘못이 아니라 **날씨 자체의 성질**이다.
   워크시트가 잔차 대신 편차를 쓴 이유(잔차는 양끝 182일이 NaN)도
   `resid.isna().sum()`으로 확인해 둔다.

4. **요일 리듬은 없다**: 시차 7의 자기상관을 원본과 편차에서
   비교한다.

   ```python
   t.autocorr(7), a.autocorr(7)
   ```

   원본 **0.92**, 편차 **0.03**. 원본의 0.92는 계절의 공로일 뿐,
   계절을 빼면 7일 리듬은 없다 — 기온은 달력의 요일을 모른다.
   Q12(분식집의 7일 봉우리)와 대비하는 재료.

5. **상관 0의 함정 — 시차 90일의 고리**:

   ```python
   pd.DataFrame({"90일 전": t.shift(90), "오늘": t}).plot.scatter(x="90일 전", y="오늘", s=2)
   ```

   `t.autocorr(90)`은 **-0.04**로 0에 가깝다. 그런데 점들은 둥근
   **고리 모양**이다 — 계절의 원운동(석 달 전이 봄이면 오늘은 여름,
   가을이면 겨울)이 그대로 그려진 것. 상관계수는 "직선으로 같이
   움직이는 정도"만 재므로, **상관이 0이라고 관계가 없는 게
   아니다**. Q13 토론에서 학생이 "상관 0 = 아무 관계 없음"으로
   비약하면 꺼낼 재료 — 동전은 정말 관계가 없어서 고리 무늬조차
   없는 네 귀퉁이 균일 분포가 된다.
