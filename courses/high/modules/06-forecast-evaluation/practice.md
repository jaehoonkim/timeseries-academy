## 2. 추가 실습 — 학생보다 한 발 더 (약 25분)

1. **alpha 사냥 — 튜닝은 훈련 구간에서**: Q15의 규칙을 직접
   실행해 본다.

   ```python
   for al in [0.1, 0.3, 0.5, 0.7, 0.9]:
       p = t.ewm(alpha=al).mean().shift(1)
       tr = (train - p[train.index]).abs().mean()
       te = (test - p[test.index]).abs().mean()
       print(al, round(tr, 2), round(te, 2))
   ```

   훈련 MAE는 0.1의 **2.60**에서 0.9의 **1.61**까지 단조로
   좋아진다 — 훈련 성적으로 고르면 alpha = 0.9. 시험 성적도
   **1.66**으로 순서가 유지된다(이번엔 훈련의 결론이 시험에서
   배신하지 않는 경우). 그리고 0.9의 1.66조차 naive의 1.63에 못
   미친다 — alpha를 올릴수록 naive에 **다가갈 뿐 넘지 못한다**
   (Q13의 수치 버전).

2. **창 크기 사냥**: 이동평균도 같은 방향인지 확인한다.

   ```python
   for w in [2, 3, 7, 14, 30]:
       p = t.rolling(window=w).mean().shift(1)
       print(w, round((test - p[test.index]).abs().mean(), 2))
   ```

   창 2일 **1.95** → 7일 **2.30** → 30일 **3.21**. 창을 줄일수록
   좋아지고, 극한(창 1일)이 naive다. "기억을 길게 섞을수록
   예측은 나빠진다" — 두 평활 선수가 같은 이유로 진다.

3. **naive의 아픈 달**: 시험 구간 naive 오차를 월별로 쪼갠다.

   ```python
   e = test - pred_naive
   e.abs().groupby(e.index.month).mean().round(2)
   ```

   8월 **0.82**, 9월 0.89가 쉽고 12월 **2.97**, 2월 2.31, 1월
   2.27이 어렵다 — 겨울이 전환점(한파의 시작과 끝)의 계절이다.
   H7에서 "무엇을 특징으로 넣어야 하나"의 힌트로 쓸 재료.

4. **최악의 날 수집**: naive의 큰 미스 셋을 모아 본다.

   ```python
   e.abs().nlargest(3)
   ```

   2026-02-06 **8.4도**(1.7 → -6.7), 2026-01-11 **8.0도**(0.7 →
   -7.3), 2026-04-20 **7.9도**(20.3 → 12.4). 셋 다 하루 만에
   기온이 급변한 날 — naive의 실패는 무작위가 아니라 **전환점에
   몰려** 있다.

5. **RMSE/MAE 비율 — 선수의 스타일 읽기**: 순위표의 두 심판
   점수로 비율을 내 본다. 평균 **1.14**, 계절 naive **1.27**,
   naive **1.38**. 비율이 클수록 "가끔 크게 틀리는" 타입이다 —
   naive는 평소엔 제일 정확하지만 틀릴 때 제일 크게 틀린다.
   MAE 순위와 RMSE 순위가 뒤집히는 선수가 없는지도 확인해 둔다
   (오늘은 없다 — 뒤집히는 데이터도 있다).
