# H6. 예측과 평가 — 정답 및 완성 예시

## worksheet 정답

- **Q1.** 예측: -1.0, -4.7, -10.4, -11.0, -10.6, -8.0, -7.3.
  오차: **-3.7, -5.7, -0.6, +0.4, +2.6, +0.7, -0.9**.
- **Q2.** 절댓값 합 **14.6**, MAE = 14.6 ÷ 7 ≈ **2.1°C**.
- **Q3.** 제곱 합 **54.76**(13.69 + 32.49 + 0.36 + 0.16 + 6.76 +
  0.49 + 0.81), 제곱 평균 **7.82**, RMSE ≈ **2.8°C**.
- **Q4.** 한파가 **시작되던 이틀**(1/19 오차 -3.7, 1/20 오차
  -5.7). 이 이틀의 제곱만으로 46.2 — 제곱 합 54.8의 84%를
  차지한다. H5 Q14에서 본 전환점이 RMSE를 끌어올린다.
- **Q5.** 훈련 **731**일, 시험 **365**일. 여기저기서 아무 날들을
  뽑으면 시험 날짜의 이웃(어제·내일)이 훈련에 남는다 — 시계열은
  이웃끼리
  닮아 있으므로(H5의 자기상관) 미래 정보가 새는 반칙이 된다.
  실전(내일을 모르는 채 예측)과 같은 조건이 되려면 시간 순서로
  잘라야 한다.
- **Q6.** train.mean() = **12.6°C**. 평균 선수: MAE **9.8**,
  RMSE **11.2**.
- **Q7.** rolling의 창에는 **오늘이 포함**되므로(H3) 그대로 쓰면
  오늘의 예측에 오늘 기온이 들어간다 — 미래 금지 규칙 위반.
  `.shift(1)`로 하루 밀면 "어제까지의 정보"가 된다. ewm도 같은
  이유.
- **Q8.** 순위표 (MAE / RMSE, °C):

  | 선수 | MAE | RMSE |
  |---|---|---|
  | 평균 | 9.8 | 11.2 |
  | naive | **1.6** | **2.3** |
  | 계절 naive | 3.3 | 4.2 |
  | 이동평균(7일) | 2.3 | 3.0 |
  | 지수평활(0.3) | 2.0 | 2.7 |

- **Q9.** 우승 **naive** — H5의 어림 1.6도가 정식 규칙에서
  재현됐다. 이유: 시차 1 자기상관이 0.98로, 오늘이 내일을 가장
  많이 말해 주는 데이터다 — 가장 가까운 과거가 가장 좋은 예측
  재료.
- **Q10.** 이동평균·지수평활은 과거 여러 날을 섞어서 매끈해지는
  대신 **늦는다**(H3의 지연). 예측 재료로 보면 자기상관이 약한
  먼 시차(2일, 3일, …)를 섞어 쓰는 셈이라, 가장 강한 재료(어제)
  하나만 쓰는 naive보다 나쁘다. 매끈함은 보기의 미덕이지 예측의
  미덕이 아니다.
- **Q11.** 최악의 날 **2026-04-14**, 오차 **13.1도** — 실제
  **17.6°C**(따뜻한 봄날)인데 작년 같은 날(2025-04-14)은
  **4.5°C**(꽃샘추위)였다. 계절 naive는 **작년의 날씨 사건**을
  올해 예보로 그대로 복사한다 — 계절은 해마다 돌아오지만 사건은
  해마다 다르다.
- **Q12.** 최악의 날 **2026-02-06** — 전날 **1.7°C**, 당일
  **-6.7°C**(하루에 8.4도 급락). 이런 날의 이름은 **전환점**
  (H5 Q14). naive는 변화를 하루 늦게 따라간다.
- **Q13.** alpha → 1이면 "새 소식 100% + 기억 0%" — **naive**가
  된다. 실제로 alpha를 올릴수록 성적이 naive에 다가간다(0.3에서
  2.0, 0.9에서 1.7 — naive는 1.6). 매끈한 그래프와 정확한 예측은
  같은 것이 아니다 — 평활을 강하게 할수록 그래프는 예뻐지고
  예측은 나빠지는, 오히려 반대 방향이다.
- **Q14.** **shift(7)**. 분식집 손님 수의 주기는 요일(H5 Q12의
  ACF 봉우리 = 7일)이므로 "지난주 같은 요일"이 좋은 재료다 —
  기온의 365일에 해당하는 것이 분식집의 7일이다.
- **Q15.** 시험 구간 성적을 보고 alpha를 고르는 순간, 시험지를
  미리 본 것과 같다 — 그렇게 고른 값이 진짜 미래에서도 좋으리란
  보장이 없다. alpha는 **훈련 구간의 성적**으로 고르고, 시험
  구간은 최종 채점에 한 번만 쓴다.

## practice 추가 실습 정답

- **alpha 사냥**: 훈련 MAE 0.1 → 2.60, 0.3 → 1.98, 0.5 → 1.79,
  0.7 → 1.67, 0.9 → **1.61** (시험은 각각 2.53, 2.02, 1.86, 1.74,
  **1.66**). 훈련 성적으로 고르면 0.9이고 시험에서도 순서가
  유지된다. 0.9의 1.66도 naive(1.63)에 못 미친다 — 올릴수록
  naive에 다가갈 뿐 넘지 못한다.
- **창 크기 사냥**: 시험 MAE 창 2일 **1.95**, 3일 2.10, 7일
  2.30, 14일 2.50, 30일 **3.21**. 창을 줄일수록 좋아지고 극한
  (창 1일)이 naive — 지수평활의 alpha 올리기와 같은 방향.
- **naive의 아픈 달**: 월별 MAE — 8월 **0.82**, 9월 0.89, 3월
  1.01, 7월 1.02가 쉽고 / 12월 **2.97**, 2월 2.31, 1월 2.27, 11월
  2.12가 어렵다. 겨울이 전환점의 계절이다.
- **최악의 날 수집**: 2026-02-06 **8.4도**(1.7 → -6.7),
  2026-01-11 **8.0도**(0.7 → -7.3), 2026-04-20 **7.9도**(20.3 →
  12.4) — 셋 다 하루 만의 급변. naive의 실패는 전환점에 몰려
  있다.
- **RMSE/MAE 비율**: 평균 **1.14**, 계절 naive **1.27**, naive
  **1.38**. 비율이 클수록 "가끔 크게 틀리는" 타입 — naive는
  평소엔 제일 정확하지만 틀릴 때 제일 크다. 오늘 데이터에서는
  MAE 순위와 RMSE 순위가 같다.
- **반칙 체험(1절)**: shift 없는 이동평균은 MAE 2.0 — 정식(2.3)
  보다 좋아 보이지만 오늘 기온이 샌 점수다. 전체 평균 vs 훈련
  평균은 9.8 근처로 차이가 거의 없다 — 반칙의 크기와 반칙 여부는
  별개.

## 완성 노트북 예시 설명

- 셀 구성: ① koreanize 설치 ② import+read_csv+t ③ train/test
  분할+len ④ 평균 선수 채점(시운전) ⑤ 선수 4종 예측 정의
  ⑥~⑨ naive·계절 naive·이동평균·지수평활 채점 ⑩ 계절 naive
  최악의 날(idxmax)과 t.loc 비교 ⑪ naive 최악의 날 — 열한 셀.
- ③: (731, 365).
- ④: (9.82…, 11.17…) — 표에는 9.8 / 11.2로 적는다.
- ⑥~⑨: naive (1.63, 2.26) / 계절 naive (3.29, 4.19) / 이동평균
  (2.30, 2.97) / 지수평활 (2.02, 2.65). 표에는 소수 첫째
  자리까지.
- ⑩: (Timestamp('2026-04-14'), 13.1). t.loc["2026-04-14"] = 17.6,
  t.loc["2025-04-14"] = 4.5.
- ⑪: (Timestamp('2026-02-06'), 8.4). 전날 1.7, 당일 -6.7.
