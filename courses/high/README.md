# 고등학생 시계열 데이터 분석

서울 일별 기온 데이터 하나로 시계열 분석의 표준 파이프라인 — 탐색,
평활, 분해, 자기상관, 예측과 평가, 회귀 — 을 배우는 8모듈 과정.
전 모듈 파이썬(Colab + pandas) 기반이며, 중학생 과정과 독립적이다
(이수 전제 없음).

## 모듈

각 모듈은 75분 수업 1회 분량(고교 50분 2교시 연강 권장)이며
독립적으로 조합할 수 있다.

| # | 제목 | 핵심 내용 |
|---|---|---|
| [H1](modules/01-python-timeseries/) | 시계열과 파이썬 | 시계열 정의, Colab/pandas, 날짜 인덱스, 그래프 |
| H2 | 분포로 보는 시계열 | 표준편차, 히스토그램·상자그림, z-점수 이상치 탐지 |
| H3 | 평활 — 이동평균과 지수평활 | rolling(후행/중심), ewm, 창·α 트레이드오프 |
| H4 | 계절성과 분해 | 계절성 프로필, 편차, 추세+계절+잔차 손 분해 |
| H5 | 자기상관 | 상관계수, lag plot, ACF, naive가 강한 이유 |
| H6 | 예측과 평가 | 벤치마크 4종 대결, 홀드아웃, MAE·RMSE |
| H7 | 회귀로 예측 | 특징 만들기(월·요일·lag), 선형회귀, 벤치마크 이기기 |
| H8 | 미니 프로젝트 | 각자 데이터 수집 → 분석 → 예측 → 발표 |

서사 축: 본다 → 분포로 잰다 → 매끈하게 편다 → 쪼갠다 → 시간의 관계를
잰다 → 예측하고 평가한다 → 내 데이터로.

## 모듈 조합 가이드

- **1회 특강 (90분)**: H1 단독. 날짜 인덱스와 그래프까지 완결된 경험.
- **단기 3회**: H1 → H3 → H6. "본다 → 편다 → 예측한다" 최단 경로.
- **정규 5회**: H1 → H2 → H4 → H5 → H6. 통계·분해·자기상관 중심.
- **전체 8회**: H7(회귀)·H8(프로젝트)까지. 코딩 경험이 있는 동아리에 적합.

## 파일 구성 (모듈당 4개)

| 파일 | 용도 |
|---|---|
| `teacher.md` | 강의자 노트 — 분 단위 흐름, 설명 대본, 토론 가이드, 예상 질문, 심화 |
| `worksheet.md` | 학생 배포용 활동지 (정답 없음, 인쇄 가능) |
| `practice.md` | 강의자가 수업 전에 학습자 입장으로 직접 해보는 과제 |
| `answers.md` | worksheet·practice 정답과 완성 예시 |

## 진행 방법 (강의자)

1. 모듈의 `practice.md`를 학습자 입장으로 직접 수행한다.
2. 막힌 지점을 정리해 질문한다 — 좋은 질문은 `teacher.md` 예상 질문에 반영된다.
3. 소화가 끝나면 [PROGRESS.md](PROGRESS.md)에 체크하고 다음 모듈로 넘어간다.

## 수학·코딩 전제

- 수학: 고교 통계 기초(평균·표준편차·상관계수)를 수업 중 복습하며
  사용한다. 그 밖의 개념은 등장 전에 워크시트에서 설명한다.
- 코딩: 파이썬 경험이 없어도 H1에서 셀 실행부터 시작한다. 경험자가
  많은 반은 H1을 빠르게 통과하면 된다.

## H8용 학생 데이터 후보

- 기상자료개방포털 — 자기 동네 기온·강수량 (data.kma.go.kr)
- 한강 수위, 미세먼지 농도 (서울 열린데이터광장 data.seoul.go.kr)
- 국가통계포털 KOSIS — 인구, 물가지수 (kosis.kr)
- 네이버 데이터랩/구글 트렌드 — 검색어 관심도 추이
- 본인 스마트폰 걸음 수, 스크린타임
- 금융 데이터(주가·환율)는 가능하나 예측 난도가 매우 높음을 안내할 것
