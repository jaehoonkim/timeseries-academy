# 중학생 시계열 데이터 분석 입문

서울 일별 기온 데이터 하나로 시계열의 핵심 개념(추세, 계절성, 예측)을 배우는
8모듈 과정. 1부(M1~M5)는 구글 스프레드시트만으로 완결되고,
2부(M6~M8)는 파이썬(Colab + pandas) 확장이다.

## 모듈

각 모듈은 60~90분 수업 1회 분량이며 독립적으로 조합할 수 있다.

### 1부 — 스프레드시트로 개념 잡기

| # | 제목 | 핵심 내용 |
|---|---|---|
| [M1](modules/01-time-data/) | 시간이 담긴 데이터 | 시계열 정의, 꺾은선 그래프 읽기·그리기 |
| [M2](modules/02-averages/) | 평균의 힘과 함정 | 평균·중앙값, 이상치의 왜곡 |
| [M3](modules/03-moving-average/) | 추세 찾기 — 이동평균 | 잡음 속 추세를 이동평균으로 드러내기 |
| [M4](modules/04-seasonality/) | 반복되는 패턴 — 계절성 | 월별/요일별 패턴, 피벗 테이블 맛보기 |
| [M5](modules/05-first-forecast/) | 첫 예측 | 단순 예측(naive, 이동평균)과 오차 비교 |

### 2부 — 파이썬으로 확장 (선택)

| # | 제목 | 핵심 내용 |
|---|---|---|
| [M6](modules/06-python-revisit/) | 파이썬으로 다시 보기 | Colab 시작, pandas로 CSV 읽기, M1~M3 재현 |
| [M7](modules/07-pandas-tools/) | pandas 시계열 도구 | 날짜 인덱스, resample, rolling, 결측치 처리 |
| M8 | 미니 프로젝트 | 각자 데이터 수집 → 분석 → 예측 → 발표 |

## 모듈 조합 가이드

- **1회 특강 (90분)**: M1 단독. 그래프까지 그리면 완결된 경험이 된다.
- **단기 3회**: M1 → M3 → M5. "본다 → 추세를 찾는다 → 예측한다" 흐름.
- **정규 5회**: 1부 전체 (M1~M5).
- **코딩 병행 8회**: 전체. M6부터는 학생들의 코딩 경험 유무를 먼저 확인할 것.

## 파일 구성 (모듈당 4개)

| 파일 | 용도 |
|---|---|
| `teacher.md` | 강의자 노트 — 분 단위 흐름, 설명 대본, 예상 질문, 심화 |
| `worksheet.md` | 학생 배포용 활동지 (정답 없음, 인쇄 가능) |
| `practice.md` | 강의자가 수업 전에 학습자 입장으로 직접 해보는 과제 |
| `answers.md` | worksheet·practice 정답과 완성 예시 |

## 진행 방법 (강의자)

1. 모듈의 `practice.md`를 학습자 입장으로 직접 수행한다.
2. 막힌 지점을 정리해 질문한다 — 좋은 질문은 `teacher.md` 예상 질문에 반영된다.
3. 소화가 끝나면 [PROGRESS.md](PROGRESS.md)에 체크하고 다음 모듈로 넘어간다.

## M8용 학생 데이터 후보

각자 데이터로 확장하는 M8에서 쓸 만한, 무료로 구할 수 있는 시계열:

- 기상자료개방포털 — 자기 동네 기온·강수량 (data.kma.go.kr)
- 한강 수위, 미세먼지 농도 (서울 열린데이터광장 data.seoul.go.kr)
- 국가통계포털 KOSIS — 인구, 물가지수 (kosis.kr)
- 네이버/구글 트렌드 — 검색어 관심도 추이
- 본인 스마트폰 걸음 수, 스크린타임
