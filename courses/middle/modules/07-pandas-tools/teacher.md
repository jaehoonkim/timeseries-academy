## 예상 질문 / 오개념

- **`KeyError: '2023-08-10'`** — `index_col="date"` 없이 읽었거나
  read_csv 셀을 다시 실행하지 않은 것. 최다 빈출.
- **"`ME`, `YE`가 뭐예요?"** — Month End / Year End. 뭉친 결과에
  월말·연말 날짜로 라벨을 붙인다는 뜻. 오래된 pandas에서는 `"M"`,
  `"A"`였고 최신판은 `"ME"`, `"YE"`를 권장한다(옛 표기는 경고가 뜬다).
- **"`None`과 NaN이 달라요?"** — 우리가 넣는 건 None, pandas가
  저장할 땐 NaN으로 바뀐다. 이 수업에서는 "값 없음"으로 같다고
  생각하면 된다.
- **"loc 없이 `df["2026-01"]`은 왜 안 돼요?"** — 대괄호만 쓰면
  pandas는 **열 이름**을 찾는다. 행(날짜)을 찾을 때는 `.loc`.
- 오개념 주의: **"보간했으니 데이터가 복원됐다"** — 복원이 아니라
  추측이다. 그럴듯해 보이는 값일수록 위험하다(태풍 사흘이 26°C대의
  평범한 날들로 둔갑했다).
- 오개념 주의: **"연평균이 내려가니 추워지는 것"** — 부분 기간
  함정. 뭉친 값을 읽기 전에 몇 개를 뭉쳤는지 확인.

## 강의자용 심화

- **resample vs groupby**: `groupby(df.index.month)`는 3년치를 달력
  위치(1~12월)로 **포개고**(계절성 프로필, M4 피벗과 동일),
  `resample("ME")`는 시간축을 **유지한 채 해상도만 낮춘다**
  (다운샘플링). 전자는 계절성 분석, 후자는 추세 관찰에 맞는다 —
  M4/M3의 구분이 API 수준에서도 갈라져 있는 셈.
- **center=True의 지연 제거**는 M3 심화의 중심 이동평균 그대로:
  후행 창의 지연 ≈ (창−1)/2일이 0이 되는 대신 양끝에 NaN이 생기고
  실시간성(인과성)을 잃는다. 신호처리 용어로는 인과 필터 vs 비인과
  필터의 구분.
- **interpolate 옵션**: 기본 `linear`는 행 위치 기준 직선(우리
  데이터는 일별 등간격이라 시간 기준과 동일). `method="time"`은
  간격이 불규칙할 때 시간 비례로 채운다. 계절성이 강한 데이터라면
  "작년 같은 날 값"이나 계절성 모델 기반 보간이 더 정직할 수 있다 —
  M8에서 학생 데이터에 결측이 나오면 써먹을 이야기.
- **결측 메커니즘**: 결측이 무작위로 생겼는지(장비 무작위 고장),
  값과 관련해 생겼는지(폭풍 날 고장 — 극단값일수록 사라짐)에 따라
  처리가 달라진다. 후자를 무시한 보간·삭제는 체계적 편향을 만든다 —
  통계학의 MCAR/MNAR 구분의 맛보기.
