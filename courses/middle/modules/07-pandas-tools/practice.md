## 2. 추가 실습 — 학생보다 한 발 더 (약 20분)

1. **주 단위 resample**: `df["temp_avg"].resample("W").mean().plot()`
   — 일별보다 부드럽고 월별보다 자세한 중간 해상도를 눈으로 확인.
   `resample("W").count()`의 첫 주가 7이 아닌 것(부분 주 — 데이터가
   화요일에 시작)도 찾아볼 것. Q6의 부분 기간 함정이 주 단위에서도
   반복된다.
2. **한파 보간 실험**: 태풍 대신 한파 사흘(2026-01-20~22)을 지우고
   보간해 본다. 보간값 -5.5 / -6.4 / -7.2 vs 실제 -10.4 / -11.0 /
   -10.6 — 이번에도 사건이 온화한 직선으로 덮인다. 태풍(여름)과
   한파(겨울) 두 사례를 갖고 있으면 수업 중 예시를 바꿔 쓸 수 있다.
3. **groupby vs resample 비교**: `df.groupby(df.index.month)["temp_avg"].mean()`
   (12개, M4 피벗과 동일)과 `resample("ME").mean()`(36개)을 나란히
   실행해 Q5의 구분을 직접 확인한다.
