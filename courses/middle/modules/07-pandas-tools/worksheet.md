## 3. resample — 시간 단위를 바꾸는 도구

M4에서 월별 평균을 내려면 세 단계가 필요했다: ① `=MONTH()`로 월 열
만들기 ② 피벗에서 행=월로 묶기 ③ 값을 AVERAGE로 바꾸기.
날짜 인덱스가 있으면 **resample**이라는 도구가 이걸 한 줄로 한다.
먼저 읽는 법부터:

> `df["temp_avg"].resample("ME").mean()`
> = temp_avg를 / **월 단위로 다시 묶어서** / 묶음마다 **평균**

- `resample(...)` — "시간 단위로 다시 묶기". 일별 데이터를 월별·주별·
  연별 묶음으로 바꾼다 (피벗의 "행=월" 역할).
- `"ME"` — 어떤 단위로 묶을지. Month End의 약자로, 월 단위로 묶고
  결과에 월말 날짜 라벨을 붙인다는 뜻.
- `.mean()` — 묶음마다 어떻게 요약할지 (피벗의 "값=AVERAGE" 역할.
  `.max()`로 바꾸면 월별 최고값이 된다).

이제 실행해 보자:

```python
monthly = df["temp_avg"].resample("ME").mean()
monthly
```


## 4. rolling의 숨은 옵션 — 지연 없는 이동평균

M3에서 이동평균이 급락을 **며칠 늦게** 따라가는 것을 봤다.
창을 뒤가 아니라 **가운데**에 놓으면 지연이 사라진다:

```python
avg = df["temp_avg"]
compare = pd.DataFrame({
    "actual": avg,
    "trailing": avg.rolling(7).mean(),
    "centered": avg.rolling(7, center=True).mean(),
})
compare.loc["2023-08"].plot()
```

## 5. 결측치 — 구멍 난 데이터 다루기

우리 데이터는 1,096일 무결점이지만, 실제 데이터에는 구멍(결측)이
흔하다. 시나리오: **태풍에 관측 장비가 사흘 고장 났다면?**

```python
broken = df["temp_avg"].copy()
broken.loc["2023-08-10":"2023-08-12"] = None
broken.isna().sum()
```

`None`은 "값 없음", `isna().sum()`은 구멍의 개수 세기다.
구멍을 **보간**(양옆을 직선으로 이어 채우기)으로 메워 보자:

```python
fixed = broken.interpolate()
fixed.loc["2023-08-09":"2023-08-13"]
```
