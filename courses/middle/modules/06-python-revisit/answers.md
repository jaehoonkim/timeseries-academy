## worksheet 정답

- **Q1.** **10.0** — M2 워밍업의 용돈 평균(1, 2, 2, 3, 42만원의 평균
  10만원)과 같은 계산이다.
- **Q2.** **1096** — 표의 행 수, 즉 3년(2023-08-01~2026-07-31)의
  일수. M1에서 부르던 "1,096일"이 그대로 확인된다.
- **Q3.** **2026-07-31**. 시작(head)은 2023-08-01 — 1부 내내 쓰던
  바로 그 데이터다.
- **Q4.** 여름 봉우리 3개와 겨울 골짜기 3개가 반복되는 물결 —
  M1의 3년 그래프와 같은 모양이다.
- **Q5.** mean **12.71**, median **13.60**, max **32.8**, min
  **-12.3**. 서울 기온으로 상식적인 범위(-20~40°C) 안이므로
  "오타 없음, 통과" — M2 practice의 오타 탐지 흉내와 같은 결론.
  (mean과 median이 1°C 가까이 다른 것도 이야깃거리: 겨울 영하
  꼬리가 평균을 아래로 끌었다 — M2의 감각으로 읽어 보기)
- **Q6.** 일치한다 — 26.1(26.14…), 25.8. 도구가 바뀌어도 데이터와
  계산이 같으면 결과가 같다.
- **Q7.** NaN(Not a Number)은 "값 없음" 표시. 7일치가 모이기 전인
  앞 6일은 계산할 수 없다 — M3에서 E2~E7이 빈칸이었던 것과 정확히
  같은 이유, 같은 위치다.
- **Q8.** 보인다 — ma365 선은 계절 물결 없이 12~13°C 부근을 지나며
  오른쪽으로 살짝 오른다(약 12.3 → 13.0). M3의 발견이 코드로
  재현된다.
- **Q9.** 시트에서 수십 분(입력, 채우기, 차트 메뉴)이던 것이 셀
  몇 개, 열 줄 남짓이 됐다. 장점 예시: 다시 실행만 하면 되는 재현성 /
  작업 과정이 코드로 남음 / 데이터가 커져도 같은 코드 / 실수를
  고치기 쉬움 (두 가지면 충분).
- **Q10.** 예시: 값 몇 개를 빠르게 확인할 때, 표를 직접 눈으로
  훑으며 고칠 때, 코드를 모르는 사람과 함께 볼 때는 시트가 낫다.
  기준 예시: "한 번 하고 말 일은 시트, 반복하거나 커질 일은 코드."

## practice 추가 실습 정답

- **M4 재현**: `groupby(df["date"].dt.month)` 결과가 1월 -3.2 /
  2월 -0.1 / … / 8월 26.7 / 12월 -0.7로 M4 피벗 표와 일치한다.
  피벗의 행=월, 값=AVERAGE가 groupby 한 줄에 대응된다.
- **M5 재현**: 1.02(naive)와 1.26(7일 평균)이 그대로 나온다.
  `shift(1)`이 "예측은 전날까지의 정보만" — M5의 한 행 밀기와 정답
  미리 보기 금지가 코드에서는 shift 하나로 표현된다.
- **심화 과제 배정 참고**: M4 재현(한 줄)은 중간 속도 학생에게,
  M5 재현(shift 개념 필요)은 가장 빠른 학생에게 적당하다.
