## 왜 파이썬인가 — 1,000일도 한 줄

- 시트에서 누른 클릭들은 기록이 남지 않는다. 코드는 요리 레시피처럼
  **남는다** — 누가 다시 실행해도 같은 결과가 나온다.

  데이터가 100만 줄이면? 코드는 여전히 **한 줄**이다.
- 오늘 1부 전체를 코드 몇 줄로 다시 해본다.

## pandas란

- 표(데이터프레임)를 다루는 파이썬 도구 상자.
- `import pandas as pd`로 불러와 `pd`라는 이름으로 쓴다.
- 시트에서 표를 다루던 것을, pandas에서는 코드로 다룬다.

---

## CSV 읽기 — 데이터 불러오기

```python
import pandas as pd

url = "https://raw.githubusercontent.com/jaehoonkim/timeseries-academy/main/data/seoul-temp-daily.csv"
df = pd.read_csv(url, parse_dates=["date"])
df
```

따옴표·괄호까지 정확히 입력해야 한다.

---

## 한 줄씩 읽는 법

| 코드 | 하는 일 | 시트에서는 |
|---|---|---|
| `import pandas as pd` | 표 전용 도구 상자를 꺼내 `pd`라고 부르기 | (시트를 여는 것) |
| `pd.read_csv(url, ...)` | 주소에서 CSV 읽어 오기 | `=IMPORTDATA(...)` — **같은 주소다!** |
| `parse_dates=["date"]` | date 열을 날짜로 인식시키기 | 서식 → 숫자 → 날짜 (M1의 45139 사건) |
| `df = ...` | 읽어 온 표를 `df`라는 이름에 담기 | (시트 문서 그 자체) |

---

## 확인해 보기 — len과 tail

```python
len(df)
```

```python
df.tail()
```

`len(df)`는 표의 행 수, 즉 데이터가 며칠치인지 알려준다. `tail()`은
표의 끝부분 몇 줄을 보여준다 — 결과는 활동지에서 직접 확인한다.

---

## M1 재현 — 그래프 한 줄

```python
df.plot(x="date", y="temp_avg")
```

범위 선택 → 삽입 → 차트로 몇 번 클릭하던 일이 한 줄이 된다.

```python
df.plot(x="date", y=["temp_avg", "temp_max", "temp_min"])
```

`y`에 열 이름을 리스트로 주면 선을 여러 개 한 번에 그린다.

---

## M2 재현 — 평균과 중앙값

```python
df["temp_avg"].mean()
df["temp_avg"].median()
df["temp_avg"].max()
df["temp_avg"].min()
```

- `df["열이름"]`으로 한 열만 뽑아, 그 뒤에 `.mean()`처럼 함수를
  붙인다.
- max·min으로 상식적인 범위인지 확인하는 것도 코드로 할 수 있다 —
  M2의 오타 탐지를 코드로 하는 셈이다.

---

## M3 재현 — 이동평균

> `df["temp_avg"].rolling(7).mean()`
> = temp_avg에 / 7일짜리 창을 하루씩 밀며(rolling) / 창마다 평균

```python
df["ma7"] = df["temp_avg"].rolling(7).mean()
df.head(10)
```

`rolling(7)`은 M3에서 손으로 밀던 바로 그 창이다. 표 앞부분에는
계산할 데이터가 모자라 **NaN**(값 없음)이 나온다 — 무엇과 같은
자리일지 활동지에서 확인해 보자.

---

## 에러를 만나면 — 에러는 정상

- **NameError: name 'df' is not defined** — 위 셀을 실행하지 않고
  아래 셀부터 실행한 것. 노트북은 **위에서부터 순서대로**.
- **SyntaxError** — 따옴표·괄호 짝이 안 맞는 것. 에러 메시지의
  화살표(^)가 위치를 가리켜 준다.
- 대소문자도 구분한다 — `df`와 `Df`는 다른 이름이다.
- 에러 메시지는 혼내는 게 아니라 **힌트**다.
