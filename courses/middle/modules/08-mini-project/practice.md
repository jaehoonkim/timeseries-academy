# M8. 미니 프로젝트 — 강의자 사전 실습

이번 practice는 워크시트 풀기가 아니라 **예시 프로젝트 완주**다.
학생이 겪을 전 과정을 한 번 통과해 봐야 순회 지도가 되고, 완성본은
수업 중 "막힌 팀에게 보여줄 예시"가 된다.

## 1. 예시 프로젝트 — "서울의 일교차는 언제 크고, 예측할 수 있을까?"

데이터는 이미 있는 CSV를 그대로 쓴다(수집 단계 생략 — 백업 데이터
3번 시나리오와 동일). Colab에서:

1. **준비**: URL로 불러오고(M7의 index_col 방식) 일교차 열을 만든다:

   ```python
   df["range"] = df["temp_max"] - df["temp_min"]
   ```

2. **분석 체크리스트**를 워크북 3번 그대로 수행한다:
   - 그래프: 어떤 모양인가? 기온(물결)과 어떻게 다른가?
   - describe/max/min: 가장 큰 일교차와 가장 작은 일교차는 언제?
     그날 무슨 날씨였을지 추측해 보자 (temp_max·temp_min을 같이 보면
     힌트가 있다).
   - 월별 groupby: M4 추가 실습에서 본 값들이 재현되는가?
   - 요일별 groupby: 패턴이 있는가?
3. **예측 대결**: 워크북 4번 코드로 마지막 31일 MAE를 잰다.
   결과가 흥미로울 것이다 — 그다음 시험 기간을 전 기간으로 늘려
   다시 재 보자.
4. **발표 준비 흉내**: 발견 3개를 뽑아 "그래프 한 장 = 발견 한 개"로
   정리해 본다. 이것이 수업 2회차에 학생들에게 보여줄 시범 발표가 된다.

## 2. 운영 준비

- **백업 데이터 2~3종**을 실제로 내려받아 CSV로 저장하고, 각각
  `read_csv`가 한 번에 되는지(인코딩·날짜 형식) 확인해 둔다.
  cp949 파일을 하나 일부러 포함시켜 깨짐 → 해결 과정을 겪어 볼 것.
- teacher.md의 **루브릭**을 소리 내어 읽고, 각 항목을 예시 프로젝트에
  적용해 자기 발표를 채점해 본다 — 루브릭의 감이 생긴다.
- 날짜 형식이 다른 CSV(예: "2026.08.17")를 하나 만들어
  `pd.to_datetime(..., format=...)` 해결을 연습해 둔다.
