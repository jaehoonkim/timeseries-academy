## 4. 예측 대결 (M5·M6)

내 데이터에서 "내일은 오늘과 같다"와 이동평균을 겨루게 하자.
마지막 구간을 미래인 척 떼어 놓고(홀드아웃), 평균 오차(MAE)로 판정:

```python
actual = df["값열"]
pred_naive = actual.shift(1)
pred_ma = actual.rolling(window=7).mean().shift(1)

n = 31  # 시험 기간(행 수) — 내 데이터에 맞게
print("내일은 오늘과 같다:", (pred_naive - actual).abs().tail(n).mean())
print("이동평균:", (pred_ma - actual).abs().tail(n).mean())
```

`.shift(1)`이 "예측(forecast)은 전날까지의 정보만"이라는 규칙이다 —
**정답 미리 보기 금지**(M5)가 코드 한 조각에 들어 있다.
