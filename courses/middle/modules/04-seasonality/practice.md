# M4. 반복되는 패턴 — 계절성 — 강의자 사전 실습

## 1. 워크시트 전체 수행 (약 40분)

[worksheet.md](worksheet.md)를 학생처럼 순서대로 푼다. 특히:

- 피벗 테이블이 처음이면 여기서 충분히 헤맬 것 — 값 요약 기준을
  SUM에서 AVERAGE로 바꾸는 메뉴 위치를 눈감고도 찾을 수 있어야
  수업 중 15명을 도울 수 있다.
- 피벗의 **행/열/값** 세 자리에 무엇을 넣으면 무엇이 나오는지,
  이것저것 넣어 보며 감을 잡을 것 (행에 연도, 열에 월을 넣으면
  표가 어떻게 뒤집히는지 등).

## 2. 추가 실습 — 학생보다 한 발 더 (약 20분)

1. **일교차의 계절성**: H1에 `일교차`, H2에 `=C2-D2` 입력 후 채우기.
   피벗(행 `월`, 값 `일교차` AVERAGE)으로 월별 일교차를 구한다.
   M1에서 눈으로 관찰했던 "봄가을에 넓고 여름에 좁다"가 숫자로
   확인되는가? 가장 넓은 달과 가장 좁은 달은?
2. **편차(anomaly) 계산**: 태풍 카눈 날(2023-08-10)의 22.0°C는
   2023년 8월 평균과 몇 도 차이인가? 연도별 피벗에서 2023년 8월
   평균을 읽어 빼 보자. "8월치고 몇 도 서늘했다"를 숫자로 말하는
   연습이다.
3. 요일 피벗에 값 `temp_avg`를 **한 번 더** 추가해 두 번째는 MAX로
   바꿔 보자 — 같은 피벗에 평균과 최댓값을 나란히 놓을 수 있다.
   피벗 값 자리는 여러 개를 받는다는 것을 알아 두면 응용이 넓어진다.
