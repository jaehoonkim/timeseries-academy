## 2. 월별 평균 — 피벗 테이블 맛보기

M1의 3년 시트에서 1,096일을 **달별로** 뭉쳐 보자.

1. I1 셀에 제목 `월`, I2 셀에 `=MONTH(A2)` 입력 후 채우기 핸들
   더블클릭. (1~12 숫자가 나온다 — A열 날짜에서 월만 꺼낸 것)
2. 데이터 범위 안의 아무 셀이나 선택 → 삽입 → **피벗 테이블** → 새 시트.
3. 오른쪽 편집기에서 — 행: `월` 추가, 값: `temp_avg` 추가.
4. 값이 이상하게 크게 나올 것이다. 값의 **요약 기준을 SUM에서
   AVERAGE로** 바꾼다.
5. 완성된 표(월 1~12, 평균기온)를 선택해 꺾은선 그래프를 만든다.
