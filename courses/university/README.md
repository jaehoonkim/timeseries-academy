# 대학생 시계열 데이터 분석

서울 일별 기온과 일별 수요 데이터, 성격이 다른 두 시계열로 고전
시계열 모형(STL·ETS·ARIMA/SARIMA)과 특징 기반 ML을 정식으로 배우고
대결시키는 8모듈 과정. 전공 무관 교양 수준이며, 중등·고등 과정과
독립적이다(이수 전제 없음).

## 모듈

각 모듈은 90분 수업 1회 분량이며 독립적으로 조합할 수 있다.

| # | 제목 | 핵심 내용 |
|---|---|---|
| [U1](modules/01-pipeline-revisit/) | 파이프라인 압축 재구축 | 두 데이터 탐색, 프로필·편차, naive의 벽, 홀드아웃·MAE/RMSE |
| [U2](modules/02-stl-decomposition/) | 분해 정식 — STL | 손 분해의 자동화, 추세/계절/잔차, 두 데이터의 분해 대조 |
| [U3](modules/03-acf-pacf-stationarity/) | 시계열의 어휘 — ACF·PACF와 정상성 | ACF·PACF, 정상성, 차분이라는 처방 |
| [U4](modules/04-exponential-smoothing/) | 지수평활 가족 — ETS | SES → Holt → Holt-Winters, 배합의 정식 모형화 |
| [U5](modules/05-arima/) | ARIMA | AR·MA의 뜻, 차수 고르기(ACF/PACF + AIC), 잔차 진단 |
| U6 | SARIMA와 예측 구간 | 계절 차수, 점 예측에서 구간 예측으로 |
| U7 | 특징 기반 ML 도전 | lag·달력·rolling 특징, 부스팅, rolling-origin 교차검증, 고전과의 대결 |
| U8 | 파이널 프로젝트 | 각자 데이터로 전 과정 + 모형 대결 + 구간 예측, 발표 |

서사 축: 벽을 다시 세운다 → 쪼개서 듣는다 → 어휘를 갖춘다 →
고전의 대가들 → 도전자 ML → 내 데이터로.

두 데이터의 역할: 기온은 관성·연 주기의 세계(ETS·ARIMA가 강한
무대), 수요 데이터는 달력의 세계(요일·공휴일 특징을 쥔 ML이 강한
무대) — U7의 대결에서 승자가 데이터마다 갈리는 것이 과정의 결론
문장이다.

## 모듈 조합 가이드

- **1회 특강 (90분)**: U1 단독. 탐색부터 벤치마크 채점까지 한
  바퀴가 완결된 경험.
- **고전 코스 5회**: U1 → U3 → U4 → U5 → U6. 어휘를 갖추고
  ETS·ARIMA·구간 예측까지.
- **ML 코스 3회**: U1 → U2 → U7. 분해로 데이터를 이해하고 특징
  설계로 직행.
- **전체 8회**: U8(프로젝트)까지. 학기 중 격주 세미나 또는 방학
  집중 과정에 적합.

## 파일 구성 (모듈당 5개)

| 파일 | 용도 |
|---|---|
| `slides.md` | 워크시트 전에 진행하는 이론 강의 슬라이드 (Marp) — 강의자가 practice 소화를 마친 모듈부터 작성 |
| `teacher.md` | 강의자 노트 — 분 단위 흐름, 설명 대본, 예상 질문, 심화 |
| `worksheet.md` | 학생 배포용 활동지 (정답 없음) |
| `practice.md` | 강의자가 수업 전에 학습자 입장으로 직접 해보는 과제 |
| `answers.md` | worksheet·practice 정답과 완성 예시 |

슬라이드 렌더링: `npx -y @marp-team/marp-cli modules/<모듈>/slides.md -o slides.pptx`

## 진행 방법 (강의자)

1. 모듈의 `practice.md`를 학습자 입장으로 직접 수행한다.
2. 막힌 지점을 정리해 질문한다 — 좋은 질문은 `teacher.md` 예상
   질문에 반영된다.
3. 소화가 끝나면 [PROGRESS.md](PROGRESS.md)에 체크하고 다음
   모듈로 넘어간다.

## 수학·코딩 전제

- 수학: 고교 수학 + 대학 1학년 기초통계(평균·분산·상관·정규분포)
  수준까지만 본문에서 활용한다. 우도·상태공간·행렬 유도는 강의자
  심화에만 둔다.
- 코딩: 파이썬 경험이 없어도 U1에서 압축 재도입한다. pandas
  경험자는 U1을 빠르게 통과하면 된다.
- 라이브러리: Colab 기본 제공만 사용 — pandas, matplotlib,
  statsmodels, scikit-learn. 추가 설치 없음.

## U8용 학생 데이터 후보

- 기상자료개방포털 — 자기 동네 기온·강수량 (data.kma.go.kr)
- 서울 열린데이터광장 — 지하철·따릉이·미세먼지 (data.seoul.go.kr)
- 국가통계포털 KOSIS — 물가지수, 산업 지표 (kosis.kr)
- 한국은행 ECOS — 환율, 금리 (ecos.bok.or.kr)
- 네이버 데이터랩/구글 트렌드 — 검색어 관심도
- Kaggle·데이콘 시계열 대회 데이터 — 평가 지표가 이미 정의된 무대
- 금융 데이터(주가·코인)는 가능하나 naive를 이기기 극히 어려움을
  안내할 것 — 그 자체가 효율적 시장의 수업 재료다
