## 2. 추가 실습 — 본문이 한 줄로 지나간 것들 (약 20분)

1·2번은 수업 전에 꼭, 3·4번은 여유가 있을 때만.

1. **명절 날만 채점** (Q4 답의 223만/57만):

   ```python
   test_hols = holidays[(holidays >= "2025-08-01") & (holidays.dayofweek < 5)]
   (round((y1_test[test_hols] - pred1[test_hols]).abs().mean() / 1e4, 1),
    round((y2_test[test_hols] - pred2[test_hols]).abs().mean() / 1e4, 1))
   ```

   시험 기간 평일 빨간 날 15일 — 요일까지 **223.4만** vs
   빨간날 **57.1만**. RMSE 반토막의 정체.
2. **기온에도 빨간날을 줘 보기**: 1절의 X에 빨간날 열을 추가해
   재채점 — **1.70 / 2.23**으로 사실상 변화 없다(빨간 날에
   기온은 변하지 않는다). 특징은 넣는다고 좋아지는 게 아니라
   **데이터가 그 정보로 움직일 때만** 힘을 쓴다 — Q6 기온 답의
   실측 근거.
3. **심판의 다섯 판정 개별 보기**: 4절 셀의 마지막 줄을
   `[round(x / 1e4, 1) for x in maes]`로 바꿔 폴드별 값을 본다
   — 요일까지 [51.5, 52.5, 43.5, 45.2, 43.1], 빨간날까지
   [51.5, 52.5, 43.5, **21.0**, **21.3**]. 앞 세 폴드가 똑같은
   이유: 배움 토막이 짧을 때는 빨간 날 표본이 몇 개 안 돼
   나무가 그 재료를 아직 쓰지 못한다 — **드문 특징은 데이터가
   쌓여야 힘을 쓴다**(teacher 심화).
4. **연휴 전날 특징**: "내일이 빨간 날인가" 열을 추가해 본다
   (`s.index.isin(holidays - pd.Timedelta("1D")).astype(int)`)
   — **25.1 / 40.0**으로 이득이 없다. 이득 없는 부품은 빼는
   것이 규율(U5 practice의 그 규율).
