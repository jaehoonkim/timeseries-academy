U5의 마지막 두 장면을 기억하자 — 1년 예측은 수평선으로
얼어붙었고, 지하철은 하루 앞조차 대패(MAE 124만)했다. 공통

후반부에는 이 과정 내내 미뤄 온 질문을 처리한다. 예측은 늘

미리 말해 두면, 오늘은 U5 같은 이론의 산이 아니다. 새로 배우는
것은 **계절 부품**과 **예측 구간** 둘뿐이고, 나머지는 전부 이미
아는 것의 재사용이다. 차수 고르기 같은 무거운 일은 U5에서
절차를 익혔으므로 오늘은 결과만 받아 쓴다.

```python
import pandas as pd
from statsmodels.tsa.arima.model import ARIMA

base = "https://raw.githubusercontent.com/jaehoonkim/timeseries-academy/main/data/"

```

## 1. 계절 부품 (P, D, Q, s) — 주간 naive의 두 번째 이름

SARIMA는 새 모형이 아니다. U5의 세 부품을 돌아보면 셋 다
**하루 옆**만 봤다 — AR은 어제의 값, 차분은 오늘 − 어제,
MA는 어제의 놀람(어제 예측이 빗나간 크기 — U5 3절의 그 말).
전부 한 걸음이 하루다.

그런데 지하철에서 오늘과 정말 닮은 날은 어제가 아니라 **지난주
같은 요일**이다 — U1의 성격표(두 데이터의 자기상관을 적은 그
표)에서 시차 7의 닮음(0.68)이 시차 1(0.35)의 두 배로 이미 잰
사실이다.

그래서 SARIMA는 **같은 부품 세 개를 한 벌 더** 단다. 새 벌은
과거를 볼 때 한 걸음을 하루가 아니라 s일로 걷는다 — 이 걸음의
너비 s를 **보폭**이라 부르자. 지하철의 보폭은 7일이다:

- 소문자 (p, d, q) = **보폭 1**의 세 부품 — 어제의 값, 오늘 −
  어제, 어제의 놀람. U5 그대로다.
- 대문자 (P, D, Q) = **보폭 s**의 세 부품 — 지난주 같은 요일의
  값(계절 AR), 오늘 − 지난주 같은 요일(**계절 차분**), 지난주
  같은 요일의 놀람(계절 MA).

구체 예 하나: 다음 월요일을 예측할 때 보폭 1의 AR은
일요일(어제)의 값을 재료로 쓰고, 계절 AR은 **지난 월요일**의
값을 재료로 쓴다.

계절 차분은 처음이 아니다 — U3 Q5에서 `s.diff(7)`로 손수 하던
그 주간 차분이 옵션 D가 된 것이다. U5에서 d가 `diff()`를
내장했던 것과 같은 방식이다.

차수는 (p,d,q)(P,D,Q,s)로 이어 적는다. 부품 없이 계절 차분만
있는 첫 모형부터 만들어 채점하자 — 읽는 법:

> `seasonal_order=(0, 1, 0, 7)`
> = 계절 짝은 (계절 AR 0개, 계절 차분 1번, 계절 MA 0개),
> 보폭은 7일 — 차수로 적으면 SARIMA(0,0,0)(0,1,0,7)

```python
wn_model = ARIMA(train_s, order=(0, 0, 0),
                 seasonal_order=(0, 1, 0, 7)).fit()
pred = wn_model.apply(s).predict(start="2025-08-01", end=s.index[-1])
e = test_s - pred
round(e.abs().mean() / 1e4, 1), round((e**2).mean() ** 0.5 / 1e4, 1)
```

채점 요령은 U5 2절 그대로다. 리마인드 — `apply(s)`는 훈련이
배운 계수를 **다시 배우지 않고** 전체 기간에 적용하라는
자물쇠고, `predict(…)`는 시험 구간의 하루 앞 예측들이다.
성적은 만 명 단위.

이 모형의 정체를 U5 2절의 세 단계로 밝히자: ① 모형은 계절
차분(오늘 − 지난주 같은 요일)을 배운다 ② 그런데 부품이 하나도
없어 예측되는 차분은 0이다 ③ 되돌리기 — 내일의 예측 = 지난주
같은 요일의 값 + 0.

## 2. 복수전 — 챔피언 채점과 사냥의 확인

차수는 어떻게 고를까? 절차는 U5와 완전히 같다 — U3의 지도 두
장(ACF·PACF 그림)으로 후보를 좁히고, 훈련 안의 심판
AIC(낮을수록 좋은 점수)로 정한다. 오늘은 그 절차를 반복하는 대신
**결과만 받아 쓰자**: 후보 다섯을 돌려 보면 우승은
**(1,0,1)(0,1,1,7)** — 보폭 1의 AR·MA 하나씩에 계절 MA
하나다. (대회 전체를 직접 돌려 보고 싶으면 practice에 있다.)

이 모양은 우연이 아니다. U3 Q5에서 주간 차분의 ACF에 남아
있던 구조가 정확히 둘이었다 — 어제와 닮는 관성(시차 1의
0.46)은 **보폭 1의 부품**이 잡고, 시차 7에서 뚝 끊기는 음수
막대(-0.49)는 **계절 MA**가 잡는다.
남은 구조 둘에 부품이 하나씩 — AIC가 뽑기 전에 이미 U3의
지도가 예고한 모양이다.

```python
champ = ARIMA(train_s, order=(1, 0, 1),
              seasonal_order=(0, 1, 1, 7)).fit()
pred = champ.apply(s).predict(start="2025-08-01", end=s.index[-1])
e = test_s - pred
round(e.abs().mean() / 1e4, 1), round((e**2).mean() ** 0.5 / 1e4, 1)
```

## 4. 예측 구간 — 점에서 띠로

이제 후반부다. 오늘의 새 소식은 이것이다: 모형은 예측만
내놓는 게 아니라, 자기 예측이 **얼마나 틀릴 수 있는지**도 함께
내놓을 수 있다. 그 띠가 예측 구간이다. (띠의 재료는 모형이
훈련에서 겪은 놀람의 크기인데, 계산은 모형이 다 해 준다.)

무대는 도 단위라 띠가 눈에 잡히는 기온, 선수는 U5의 챔피언
그대로다 — 읽는 법:

> `.get_prediction(start=…, end=…)`
> = predict와 같은 하루 앞 예측을, 띠까지 묶어서 내놓아라
>
> `.conf_int()`
> = 그 띠의 **아래선·위선** 두 열짜리 표를 달라 (기본이 95%)

```python
champ_t = ARIMA(train_t, order=(2, 1, 1)).fit()
gp = champ_t.apply(t).get_prediction(start="2025-08-01", end=t.index[-1])
ci = gp.conf_int()
ci.head(3).round(1)
```

출력에는 아래선·위선 두 열뿐, 몇 %짜리 띠인지는 표 어디에도
안 적혀 있다. 그건 출력이 아니라 **설정**이다 — `conf_int()`를
아무 옵션 없이 부르면 **95% 띠**를 준다(옵션의 이름은 alpha,
띠 **밖**에 남길 확률이다: 기본 0.05 = 95% 띠, 0.2로 바꾸면
80% 띠).

## 5. 부채꼴 — 멀수록 넓어진다

구간은 여러 걸음 예측에서 진가가 나온다. 기온 챔피언에게 30일
예보를 시키고 띠를 칠해 보자 — 띠가 부채처럼 펼쳐질 것이라
이런 그림을 부채꼴 도표(fan chart)라 부른다. 읽는 법:

> `champ_t.get_forecast(30)`
> = forecast의 "띠 딸린 버전" — 훈련 마지막 다음 날부터 서른
> 걸음의 가운데 선과 띠
>
> `plt.fill_between(x, 아래, 위, alpha=0.2)`
> = 두 선 사이를 칠하라 (alpha는 칠의 투명도, 0에 가까울수록
> 연하게)

```python
import matplotlib.pyplot as plt

fc30 = champ_t.get_forecast(30)
ci30 = fc30.conf_int()

test_t[:"2025-08-30"].plot(figsize=(10, 3), label="실제", legend=True)
fc30.predicted_mean.plot(label="예측", legend=True)
plt.fill_between(ci30.index, ci30.iloc[:, 0], ci30.iloc[:, 1], alpha=0.2);
```

띠의 폭도 직접 재 보자 — 위선에서 아래선을 빼면
된다(`ci30.iloc[:, 0]`은 모든 행의 첫째 열 = 아래선, `[:, 1]`은
둘째 열 = 위선. fill_between에 넣은 그 둘이다):

```python
(ci30.iloc[:, 1] - ci30.iloc[:, 0]).round(1)
```

첫날 8.1도였던 폭이 30일째에는 26.1도 — 세 배 넘게 벌어진다.

오늘의 세 문장:

1. **계절 부품 (P,D,Q,s)는 세 부품의 보폭 s 짝이다** — 주간
   naive는 SARIMA(0,0,0)(0,1,0,7)이었고, 지하철의 복수전은
   (1,0,1)(0,1,1,7)이 37.9만으로 끝냈다.
2. **절차에 새것은 없었다** — 채점도 잔차 진단도 차수 고르기도
   U5 그대로. 계절이 있어도 순서는 같다.
3. **예측은 띠로 말한다** — 약속(95%)의 채점은 띠 안 비율이고,
   멀수록 넓어지는 것은 모형의 정직이다.
