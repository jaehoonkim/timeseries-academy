## 2. 추가 실습 — 본문이 결과만 받아 쓴 것들 (약 20분)

워크시트가 가볍게 지나간 자리를 직접 확인한다. 1·2번은 수업
전에 꼭, 3·4번은 여유가 있을 때만.

1. **후보 대회 재현** (본문 2절이 결과만 쓴 그 대회):

   ```python
   for order, sorder in [((0,0,0),(0,1,0,7)), ((1,0,0),(0,1,0,7)),
                         ((0,0,0),(0,1,1,7)), ((1,0,0),(0,1,1,7)),
                         ((1,0,1),(0,1,1,7))]:
       r = ARIMA(train_s, order=order, seasonal_order=sorder).fit()
       print(order, sorder, round(r.aic))
   ```

   AIC 22303 → 22162 → 22064 → 21887 → **21863**(우승)을 확인.
   후보 명단의 출처는 U3 Q5의 두 구조다 — 시차 1의 0.46(보폭
   1의 부품 몫), 시차 7의 -0.49 절벽(계절 MA 몫).
2. **커버리지 세기** (본문 4절의 93.4%):

   ```python
   inside = (test_t >= ci.iloc[:, 0]) & (test_t <= ci.iloc[:, 1])
   round(inside.mean() * 100, 1)
   ```

   비교식은 날마다 참/거짓, `&`는 "둘 다 참", mean은 참을 1로
   친 평균 = 띠 안 비율. **93.4**가 나온다. 지하철 챔피언에
   같은 요령을 쓰면 **96.2%**(폭은 ±209만 — 명절의 큰 놀람까지
   담느라 넓다).
3. **params 구경**: `champ_t.params.round(2)` — sigma2
   **4.28**의 제곱근 2.07에 1.96을 곱해 두 배 하면 **8.1** =
   구간의 폭. 띠가 U5 "놀람의 분산"의 재활용임을 검산.
   (지하철 `champ.params.round(2)`는 sigma2가 1조 단위라 표
   전체가 지수 표기로 나온다 — `8.8e-01` = 0.88.)
4. **80% 구간**: `gp.conf_int(alpha=0.2)` — 폭 5.3도, 띠 안
   비율 84.1%. 좁게 말하면 자주 틀린다 — 확신의 폭과 맞는
   빈도의 거래.
