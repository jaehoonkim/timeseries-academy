## 2. 추가 실습 — 학생보다 한 발 더 (약 25분)

1. **시험 성적 전수 확인**: 4절의 for 루프를 확장해 여섯 차수
   전부의 하루 앞 성적을 채점한다(apply 요령을 루프 안에). MAE
   순위 — (2,1,1) 1.53, (2,1,0) 1.56, (1,1,1) 1.60, (0,1,1)
   1.62, (1,1,0) 1.63, (0,1,0) 1.63 — 가 AIC 순위와 정확히 같은
   순서임을 확인.
2. **SES와의 동치**: (0,1,1)의 성적 1.62가 U4 SES(1.63)와 거의
   같다 — ARIMA(0,1,1)은 SES와 수학적으로 동치인 모형이다(teacher
   심화). 두 가족이 겹치는 지점을 눈으로.
3. **Ljung-Box 검정**:

   ```python
   from statsmodels.stats.diagnostic import acorr_ljungbox
   acorr_ljungbox(champ.resid.iloc[1:], lags=[10])
   ```

   p값이 크면(0.05 이상) "구조 없음을 기각하지 못함" — 눈
   판정(Q6)의 정식 버전. 시차 8 막대 하나에도 불구하고 통과함을
   확인.
4. **더 큰 차수의 함정**: (5,1,5)를 fit해 본다 — 수렴 경고가
   나고 AIC는 **3140**으로 (2,1,1)의 3141과 사실상 동률(1점
   차)이다. 부품을 아홉 개 더 쓰고도 이득이 없다 — AIC 차이가
   이 정도면 **단순한 쪽을 고르는 것이 규율**이다(간결성 원칙,
   수렴도 불안정해진다).
5. **지하철 대패 재현**: `ARIMA(train_s, order=(1,1,1))`을
   apply 요령으로 채점 — 하루 앞 MAE 123.9만 / RMSE 138.4만.
   주간 naive(55.5만)에게도 대패 — U6 오프닝의 실측 근거.
