## 1. AR — 자기 자신에게 배우는 식

**AR**(autoregressive, 자기회귀)의 식은 U4의 배합과 닮았다:

> 오늘 = 상수 + **φ × 어제** + 오차

어제 값에 계수 φ를 곱해 더하는 식을 데이터에 맞추는 것 — "자기
자신의 과거에 대한 회귀"라서 자기회귀다. U4 배합과의 차이는
**계수의 자유**다: α는 0과 1 사이에 갇혀 있었지만, φ는 음수도
되고, 어제·그제 두 개(AR(2))로 늘릴 수도 있다.

U3에서 "직접 정보는 어제뿐"이라 판독했던 기온의 **편차**에
맞춰 보자 — 읽는 법:

> `ARIMA(dev_train, order=(1, 0, 0))`
> = 편차에 ARIMA를 놓되 차수는 (AR 1개, 차분 0번, MA 0개) —
> 곧 순수한 AR(1)
>
> `.fit()` / `.params`
> = 계수를 배우고 / 배운 계수를 보여 달라 (U4와 같은 동작)

```python
from statsmodels.tsa.arima.model import ARIMA

dev = t - t.groupby(t.index.month).transform("mean")
dev_train = dev[:"2025-07-31"]

ar1 = ARIMA(dev_train, order=(1, 0, 0)).fit()
ar1.params.round(2)
```

## 2. I — 차분 부품, 그리고 벽의 세 번째 정체

order의 가운데 자리 **d**가 **I**(integrated) 부품 — 모형에
들어가기 전에 **차분을 d번** 하라는 뜻이다. U3의 그 차분이 모형
안으로 들어온 것이다.

그럼 이 모형은 무엇일까 — AR도 MA도 없이 차분만:

```python
naive_model = ARIMA(train_t, order=(0, 1, 0)).fit()
```

하루 앞 채점을 하자. 요령은 U4와 같은 정신인데 도구가 더
깔끔하다 — 읽는 법:

> `naive_model.apply(t)`
> = 훈련이 배운 계수를 **그대로**(다시 배우지 않고) 전체 기간에
> 적용하라 — U4의 optimized=False와 같은 자물쇠
>
> `.predict(start="2025-08-01", end=t.index[-1])`
> = 그 구간의 **하루 앞 예측**들을 내놓아라

```python
pred = naive_model.apply(t).predict(start="2025-08-01", end=t.index[-1])
e = test_t - pred
round(e.abs().mean(), 2), round((e**2).mean() ** 0.5, 2)
```

## 3. MA — 오차의 기억 (이름 함정 주의)

세 번째 부품 **MA**의 식:

> 오늘 = 평균 + 오차 + **θ × 어제의 오차**

어제의 예측이 얼마나 **빗나갔는지**(어제의 놀람)를 기억했다가
오늘 예측에 반영하는 부품이다 — 어제 크게 놀랐으면 오늘은 그
놀람의 θ만큼을 이어받는다.

이름 함정: MA는 moving average의 약어지만 **U2의 rolling
평균과는 무관하다** — 역사적 사연으로 이름만 같은 남남이다.
이 과정에서는 "오차의 기억"으로만 부르자.

AR과 MA는 어떻게 가려 쓰나? U3의 지도 두 장이 판독 규칙이다:

- ACF **꼬리** + PACF **절벽**(시차 p에서) → **AR(p)**
- ACF **절벽**(시차 q에서) + PACF **꼬리** → **MA(q)**
- 둘 다 꼬리 → **섞는다**(AR + MA)

## 4. 차수 고르기 — 후보 대회

기온 원본에는 d=1을 주고, AR·MA 차수를 바꿔 가며 AIC를 재자.
같은 일을 여섯 번 반복하므로 **반복문**을 처음 쓴다 — 읽는 법:

> `for order in [...]:`
> = 목록의 항목을 **하나씩 꺼내** order라는 이름으로 부르며,
> 들여쓰인 줄들을 항목마다 반복하라

```python
for order in [(0,1,0), (1,1,0), (0,1,1), (1,1,1), (2,1,0), (2,1,1)]:
    r = ARIMA(train_t, order=order).fit()
    print(order, round(r.aic))
```
