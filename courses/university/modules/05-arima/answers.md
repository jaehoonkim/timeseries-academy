# U5. ARIMA — 정답 및 완성 예시

모든 수치는 data/의 CSV(2023-08-01 시작 1,096일), 분할 2025-07-31
기준. AIC·계수는 statsmodels ARIMA(statespace) 구현 기준으로
버전에 따라 끝자리가 흔들릴 수 있다.

## worksheet 정답

- **Q1.** φ(ar.L1) = **0.76** — U3에서 잰 편차의 시차 1 자기상관
  0.75와 같은 숫자(반올림 차이). 우연이 아니다: 재료가 하나면
  자기상관이 문자 그대로 계수가 된다.
- **Q2.** ar.L2 = **-0.24** — U3 PACF 시차 2의 그 막대가 그대로
  계수로. AIC: AR(1) **3282** → AR(2) **3240** — 부품 벌점을
  물고도 40점 이득, 그제 계수를 쓸 가치가 있다고 판정.
- **Q3.** (본문 성적 빈칸: **1.63 / 2.26**.) 되돌리기: 내일의
  예측 = 오늘 + 0 = **오늘** — 곧 **naive**다. 같은 선수의 세
  이름: U1의 벽 = U4의 SES(α=1) = U5의 ARIMA(0,1,0).
- **Q4.** AIC: (0,1,0) **3226** / (1,1,0) **3217** / (0,1,1)
  **3210** / (1,1,1) **3205** / (2,1,0) **3168** / (2,1,1)
  **3141**. 우승 **(2,1,1)** — 부품을 더할 때마다 내려가되
  조합(AR 둘 + MA 하나)에서 가장 크게 내려간다.
- **Q5.** **1.53 / 2.10** — naive(1.63/2.26)와 HW(1.55/2.14)를
  모두 제친 **새 챔피언**. AIC의 훈련 내 순위(3141 < 3168 <
  3205 < 3210 < 3217 < 3226)가 시험 MAE 순위(1.53 < 1.56 <
  1.60 < 1.62 < 1.63 = 1.63)와 정확히 같은 순서 — 훈련 안의
  심판이 시험 순위를 예언했다.
  - champ.params: ar.L1 **0.80**, ar.L2 **-0.31**, ma.L1
    **-0.73**, sigma2 4.28.
- **Q6.** 띠 밖 **1개**(시차 8, -0.09; 띠 ±0.07). 판정: 사실상
  **백색잡음** — 95% 띠는 구조가 없어도 스무 개 중 한 개꼴로
  우연히 밖에 나온다. U2·U3의 0.73 구조가 사라졌다 — 사냥 완료.
- **Q7.** **31**도 부근의 수평선(MAE 18.3 — U4 SES의 18.7과
  같은 참사). AR·MA의 기억은 며칠이면 소진되고, 이 모형에는
  미래로 보낼 리듬을 기억하는 부품이 없다.
- **Q8.** 공통 원인: **계절 부품의 부재**. U6이 달아 줄 것:
  계절을 아는 ARIMA(SARIMA — 지하철의 복수전), 그리고 점 예측을
  구간으로 말하는 법.

## practice 추가 실습 정답

- **시험 성적 전수**: (2,1,1) 1.53 / (2,1,0) 1.56 / (1,1,1)
  1.60 / (0,1,1) 1.62 / (1,1,0) 1.63 / (0,1,0) 1.63 — AIC
  순위와 동일한 순서.
- **SES 동치**: (0,1,1) 1.62 ≈ SES 1.63 — ARIMA(0,1,1)은 SES와
  수학적으로 동치.
- **Ljung-Box**: lb_stat 11.6, **p = 0.31** — 구조 없음을
  기각하지 못함(눈 판정의 정식 확인).
- **(5,1,5)**: 수렴 경고 + AIC **3140**(1점 차 동률) — 부품
  아홉 개를 더 쓰고도 이득 없음. 동률이면 단순한 쪽.
- **지하철 대패**: ARIMA(1,1,1) 하루 앞 **123.9만 / 138.4만**
  (주간 naive 55.5만, HW 43.5만) — 계절 없는 ARIMA의 무력함.

## 수업 전 최종 확인

- (2,1,1) fit에서 "Non-invertible starting MA parameters"
  경고가 나올 수 있다 — 시작값 이야기일 뿐 결과는 유효(수렴
  경고와는 다른 경고임을 구분해 둘 것).
- champ.resid의 첫 값은 차분 시동 전 잔차라 크게 튄다 —
  워크시트가 `.iloc[1:]`로 빼는 이유. 학생이 빼먹으면 ACF
  그림이 다르게 나온다.
- for 루프 여섯 fit은 수 초 내 — 지연 언급 불필요.
