## 2. 추가 실습 — 학생보다 한 발 더 (약 25분)

1. **막대 값을 숫자로**: 그림의 막대를 숫자로 뽑아 두면 수업 중
   판서가 정확해진다:

   ```python
   from statsmodels.tsa.stattools import acf, pacf
   acf(dev, nlags=5).round(2), pacf(dev, nlags=5).round(2)
   ```

   ACF (1.0, 0.75, 0.46, 0.29, 0.20, 0.14) / PACF (1.0, 0.75,
   **-0.24**, 0.11, -0.00, -0.01). 시차 0이 항상 1.0으로 맨 앞에
   붙어 있다는 것도 확인(자기 자신과의 닮음).
2. **PACF 시차 2의 -0.24 추궁**: 순수한 "어제뿐" 구조라면 0이어야
   한다 — 기온엔 약한 2차 구조(며칠 뒤 반락)가 있다. U5에서
   AIC가 AR(1)과 AR(2) 사이에서 고민하게 되는 복선(teacher 심화).
3. **과차분 미니 실험**: 기온을 **두 번** 차분하고 ACF를 그려
   본다 — `t.diff().diff().dropna()`. 시차 1과 2에 음수(-0.29,
   -0.25)가 **새로 생긴다**(한 번 차분의 0.11보다 나빠짐): 없던
   구조를 만들어 내는 과차분의 실물. "필요한 만큼만 차분"의
   근거.
4. **지하철 원본 PACF**: `plot_pacf(s, lags=15);` — 시차 7에
   0.56, 시차 8에 -0.35, 시차 14에 0.31. 주기 구조는 PACF에서도
   복잡한 빗살을 남긴다 — "계절은 ACF/PACF 정독보다 계절
   모형(U6)으로"의 근거를 눈으로.
5. **STL 잔차 재심문(지하철)**: `plot_acf(rs, lags=15);`(rs =
   period=7 STL 잔차) — 시차 7의 -0.49가 띠를 크게 벗어난다.
   음수도 구조라는 문장의 그림 버전.
