## 1. ACF — 닮음의 전체 지도

U1의 `autocorr(k)`는 시차 하나짜리 저울이었다. 모든 시차를
한꺼번에 재서 그려 주는 정식 도구가 **ACF**(autocorrelation
function, 자기상관 함수)다 — 읽는 법:

> `plot_acf(t, lags=400)`
> = 시차 0부터 400까지의 자기상관을 막대로 그려라
>
> 그림의 **파란 띠** = "닮음이 없어도 우연으로 나올 수 있는
> 크기"의 범위(이 데이터 길이에서는 약 ±0.06). 막대가 띠를
> 벗어나면 진짜 구조, 띠 안이면 0과 구별 불가
>
> (줄 끝 세미콜론은 U2의 그 버릇 — 그림 두 번 방지)

```python
from statsmodels.graphics.tsaplots import plot_acf, plot_pacf

plot_acf(t, lags=400);
```

## 2. 정상성 — 지도를 믿어도 되는 조건

ACF는 3년 전체를 **숫자 하나씩으로 요약**한다 — "시차 1의 닮음
0.98"처럼. 이 요약이 정직하려면 조건이 있다: 닮음의 성질이
기간 내내 **한결같아야** 한다.

**정상성**(stationarity): 평균, 출렁임의 크기, 닮음의 구조가
시간이 흘러도 변하지 않는 성질. 그래프를 아무 데서나 잘라 봐도
"언제 것인지" 구별할 수 없는 시계열이다.

기온 원본은 정상이 아니다 — 확인하자. 읽는 법:

> `t.index.month.isin([6, 7, 8])`
> = 월 번호가 이 목록에 **들어 있는가**(isin) — 참인 날만 골라
> 담는 조건

```python
summer = t[t.index.month.isin([6, 7, 8])].mean()
winter = t[t.index.month.isin([12, 1, 2])].mean()
round(summer, 1), round(winter, 1)
```

## 4. 처방 2 — 차분

두 번째 처방은 **차분**(differencing) — 값 자체 대신 "어제와의
차이"를 보는 것이다. 읽는 법:

> `t.diff()`
> = 각 날짜에서 `t - t.shift(1)`, 곧 **오늘 − 어제**를 계산하라
> (첫날은 어제가 없어 NaN)

잠깐 — `t - t.shift(1)`은 이미 본 식이다. U1 6절에서 naive를
채점한 오차가 정확히 이것이다. **차분 = naive 선수의 오차
시계열** — "차분이 백지에 가깝다"는 말은 "naive가 그만큼 잘
맞힌다"와 같은 말이다.

```python
plot_acf(t.diff().dropna(), lags=30);
```

## 5. PACF — 직접 닮음만 남기기

편차 ACF(Q4)에서 그제(시차 2)의 닮음은 0.46이었다. 그런데
이상하다 — 그제가 오늘에게 **직접** 말해 주는 게 있는 걸까,
아니면 "그제가 어제를 닮고 어제가 오늘을 닮아서" 생긴
**메아리**일까?

이 둘을 갈라 주는 도구가 **PACF**(partial autocorrelation,
부분 자기상관)다 — 시차 k의 닮음에서 그 사이 시차들을 거쳐
전파된 몫을 걷어내고 **직접 몫만** 남긴다. 읽는 법:

> `plot_pacf(dev, lags=15)`
> = 시차별 **직접** 자기상관을 그려라 — 막대가 띠를 벗어나면
> "그 시차가 직접 보태는 정보가 있다"

```python
plot_pacf(dev, lags=15);
```

## 6. 백지의 정식 이름 — 백색잡음, 그리고 재심문

U2에서 "백지"라 부른 것의 정식 이름은 **백색잡음**(white noise)
— **모든 시차에서 자기상관이 띠 안**인 시계열이다. 이제 U2의
STL 잔차를 정식 어휘로 재심문하자:

```python
from statsmodels.tsa.seasonal import STL

rt = STL(t, period=365).fit().resid
plot_acf(rt, lags=15);
```

```python
plot_pacf(rt, lags=15);
```

오늘의 세 문장:

1. **ACF는 닮음의 지도, PACF는 직접 닮음의 지도**다 — 꼬리와
   절벽의 대비가 데이터의 구조를 말한다.
2. **지도를 읽기 전에 정상에 가깝게 만들어라** — 계절을 빼거나
   (편차), 차이를 보거나(차분). 그리고 차분은 naive의 오차다.
3. **백색잡음이 될 때까지가 모형의 일이다** — 기온 잔차의 "ACF
   꼬리 + PACF 절벽"이 다음 모듈의 사냥감 프로필이다.
