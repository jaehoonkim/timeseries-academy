## 4. 규칙과 벽 (U1)

규칙을 선언한다 — 홀드아웃(뒤쪽 1/4에서 1/3을 시험으로 봉인)과
미래 금지. **이 분할 날짜는 이제 바꾸지 않는다.**

벽부터 채점한다 — naive와, 내 주기가 있다면 그 주기의 naive:

```python
train, test = v[:"분할날짜"], v["분할다음날":]

e1 = test - v.shift(1)["분할다음날":]
e7 = test - v.shift(7)["분할다음날":]   # 내 주기에 맞게
print("naive  ", round(e1.abs().mean(), 2), round((e1**2).mean()**0.5, 2))
print("주기naive", round(e7.abs().mean(), 2), round((e7**2).mean()**0.5, 2))
```

두 심판의 **간극**도 읽는다(U1의 독법): RMSE가 MAE보다 훨씬
크면 "크게 틀리는 며칠"이 있다 — 그 며칠의 정체가 내 데이터의
발견 후보다.

## 5. 고전 대표 (U4·U5·U6)

성격 판정에 따라 고전 가족의 대표를 고른다 — 후보 둘 정도를
**AIC**(훈련 안의 심판, U5)로 견주면 충분하다:

- **주기가 뚜렷하면** → 계절 부품: Holt-Winters
  (`seasonal_periods=내 주기`, U4 4절) 또는 SARIMA
  (`seasonal_order=(0,1,1,내 주기)`, U6). 단 **s=365는 fit하지
  말 것**(U6 Q7 — 대신 아래 편차 접근).
- **관성 중심이거나 주기가 길면** → ARIMA(U5 4절의 후보 대회
  축소판), 또는 **편차 접근**: 훈련 프로필을 빼고 남은 편차에
  ARIMA(U5 1절의 그 구성) —

```python
prof = train.groupby(train.index.month).mean()   # 내 주기에 맞게
dev = v - pd.Series(v.index.month, index=v.index).map(prof)
champ_c = ARIMA(dev[:"분할날짜"], order=(1, 0, 0)).fit()
pred = champ_c.apply(dev).predict(start="분할다음날", end=v.index[-1]) \
       + pd.Series(test.index.month, index=test.index).map(prof)
```

(프로필은 반드시 **train에서만** — 시험 구간이 프로필에 섞이면
반칙이다.)

채점은 늘 그대로(apply의 자물쇠, 하루 앞).

## 8. 발표 — 5분 여섯 장

그래프 한 장 = 발견 한 개.

1. **내 질문** — 한 문장.
2. **데이터** — 출처, 기간, 결측 처리.
3. **성격 판별** — 어느 세계인가, 근거(프로필·성격표) 그래프
   한 장.
4. **대결** — 벽 → 고전 → 도전자 순위표와 "어디서 벌었나".
   정직하게: 못 이겼어도 이유(성격)를 설명하면 훌륭한 발표다.
   특징 선택을 CV로 했다는 것도 한 줄 — 그것이 이 과정의
   자격증이다.
5. **띠** — 하루 앞 구간 문장과 커버리지.
6. **한계와 다음 재료** — 어떤 날들이 아직 크게 틀리는가, 무슨
   정보(열)가 있으면 깎을 수 있을까.
