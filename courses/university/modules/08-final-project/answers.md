# U8. 파이널 프로젝트 — 예시 완주와 점검 기준

학생 데이터가 제각각이라 이 모듈에는 정답지가 없다. 대신 두
가지를 둔다: practice 예시 프로젝트(일교차)의 검증된 수치와,
어떤 프로젝트에든 적용하는 점검 기준이다.

## 예시 프로젝트(일교차) 수치

모든 수치는 data/seoul-temp-daily.csv(temp_max − temp_min),
분할 2025-07-31, statsmodels·sklearn은 앞 모듈과 같은 버전 기준.

- **성격**: autocorr(1) **0.44** / autocorr(7) 0.20. 달의 보통
  4월 11.6 최대·7월 6.8 최소(산 재료), 요일 8.4~9.1(죽은 재료).
  판정: 흐릿한 관성의 세계.
- **벽**: naive **2.44 / 3.12**, 주간 naive 2.76 / 3.59. 간극
  약 1.3배 — 크게 틀리는 며칠 없음.
- **고전**: HW(s=365) 2.17 / 2.84. ARIMA 대회 — (1,0,0) AIC
  3627, (1,0,1) 3625, (0,1,1) 3635, (2,0,1) 3589, (1,1,1)
  **3588**(성적 2.00/2.54). **편차 접근**(훈련 월 프로필 제거 +
  ARIMA(1,0,0)): AIC **3545**, 성적 **1.98 / 2.51** — 대표.
  params: const 0.00, ar.L1 **0.28**, sigma2 7.41.
- **도전자**: CV(훈련, 5폴드 평균) — 월 없는 특징 넷 **2.54**
  vs 월 포함 다섯 **2.58** → 단순한 쪽 선택. 시험 **2.24 /
  2.88**. (시험을 몰래 열면 월 포함이 2.20으로 0.04 낫다 —
  심판도 못 가르는 접전이며, 결론은 어느 쪽이든 고전 승.)
- **최종**: 편차+ARIMA(1,0,0) **1.98** 우승 — 달력이 죽은
  데이터라 도전자에게 재료가 없었다. U7 결론 성립. 벽 대비
  개선 19%.
- **띠**: 편차 conf_int + 프로필. 첫날 예측 7.1, 띠 **[1.8,
  12.4]**(실제 9.3 — 안). 커버리지 **95.9%**, 폭 10.7도.

## 일지 점검 기준 (순회·발표 공통)

정직성 — 하나라도 어기면 성적 무효:

- [ ] 분할 날짜를 선언했고 이후 바꾸지 않았다
- [ ] 모든 값 특징은 shift로 밀었다(오늘 정답이 재료에 없음)
- [ ] 프로필·특징은 **train에서만** 계산했다
- [ ] 특징·차수 선택은 AIC 또는 CV로 했다(시험지는 마지막 한 번)

절차 — 여섯 개가 다 있으면 완주:

- [ ] 성격 판별(프로필의 생사 + 성격표)과 세계 판정 한 문장
- [ ] 벽 채점(naive + 주기 naive)과 두 심판 간극 읽기
- [ ] 성격과 연결된 고전 대표 선발(선발 이유 한 문장)
- [ ] 도전자(특징 목록 + CV 판정 기록)
- [ ] 최종 순위표와 "성격이 승자를 골랐는가" 문장
- [ ] 띠 한 문장 + 커버리지

## 흔한 함정 (순회 중 우선 확인)

- **프로필 누수**: `v.groupby(...)`처럼 전체로 프로필을 만들면
  시험 정보가 섞인다 — train으로만.
- **predict 이름표**: 부스팅 predict 결과에 `pd.Series(...,
  index=...)`를 빼먹으면 채점 뺄셈이 어긋난다(U7).
- **주기 바퀴 부족**: 연 리듬 데이터를 1년 반만 가져오면 훈련에
  한 바퀴도 안 남는다 — 1절 산수로 되돌릴 것.
- **s=365 fit**: 멈춘다(U6). 연 주기는 프로필·편차 접근으로.
- **결측을 무조건 채움**: 주말이 비는 데이터(주가 등)는 결측이
  아니라 "없는 날" — asfreq("D")를 강요하지 말고 있는 날들로
  진행(간격 해석만 주의, teacher 참고).
- **금융 데이터 절망**: naive를 못 이기는 것이 정상이다 — "왜
  못 이기는가"(효율적 시장)를 발견으로 쓰면 좋은 발표가 된다.
- **월별 데이터의 시차**: autocorr(1)은 "지난달", 주기는 12 —
  일별 감각(어제·7일)을 그대로 쓰지 않도록.

## 수업 전 최종 확인

- 예시 프로젝트 노트북을 완성해 두고 순회 때 화면으로 보여줄
  준비(막힌 팀에게 해당 절만).
- 편차 접근의 구간(conf_int + 프로필 되돌리기)은 예시에만 있고
  본문 코드에는 없다 — 편차 접근을 고른 팀이 구간까지 가면
  예시 노트북을 그대로 안내.
- HW(s=365) fit은 수십 초 걸릴 수 있다 — ARIMA·부스팅과 달리
  느린 것이 정상임을 미리 말해 둘 것.
