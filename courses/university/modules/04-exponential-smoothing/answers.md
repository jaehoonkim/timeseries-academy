# U4. 지수평활 가족 — ETS — 정답 및 완성 예시

모든 수치는 data/의 두 CSV(2023-08-01 시작 1,096일), 분할
2025-07-31 기준. 최적화 수치는 statsmodels holtwinters 구현
기준으로, 버전에 따라 소수 셋째 자리가 흔들릴 수 있다.

## worksheet 정답

- **Q1.** α = **1.000**. 식에 넣으면 "내일의 예측 = 오늘의 관측"
  — **naive**다. 훈련 2년이 고른 최선의 배합이 naive: U1 벽의
  정체이자 U3 "직접 정보는 어제뿐"의 모형 버전.
- **Q2.** **1.63 / 2.26** — naive와 동일. α=1이므로 당연하다.
- **Q3.** β = **0.0000**, 성적 **1.68 / 2.28** — SES보다 나쁘다.
  기온의 추세는 U2 실측으로 표준편차 0.3도(계절의 1/36)라 배울
  것이 없고, 죽은 부품은 추정 부담만 남긴다.
- **Q4.** α **0.342**, β **0.0000**, γ **0.035**. 지하철이
  어제를 1/3만 믿는 이유: 시차 1 자기상관이 0.35뿐(기온 0.98).
  U1 성격표가 배합 비율로 번역된 것.
- **Q5.** **43.5 / 79.0** (만 명) — 주간 naive(55.5/119.1)를
  두 심판 모두에서 크게 이긴다. 과정 첫 벽 돌파.
- **Q6.** 크게 번 달 **10월**(161만 → 77만), **2월**(123만 →
  87만) — 추석·설이 낀 달(수준·파형 적응 덕). 최악의 날 다섯은
  전부 공휴일: 2026-01-01(436만), 2026-02-16 설(399만),
  2025-10-06 추석(376만), 2026-03-02 삼일절 대체(367만),
  2026-06-03 지방선거(349만). 남은 숙제 = 달력.
- **Q7.** **1.55 / 2.14** — naive의 벽(1.63/2.26)을 넘는다.
  α=1(어제 100%)은 그대로이고, **훈련에서 추정된 고정 연 파형**
  (γ=0)이 "내일과 오늘의 계절 차이"를 보태 준 것 — naive가
  전환점에서 하루 늦는 몫의 일부를 미리 당긴다.
- **Q8.** **31.7도** 수평선(훈련 마지막 = 한여름). SES의
  기억에는 **미래로 보낼 리듬 부품이 없다** — 마지막 수준
  하나뿐. 1년 채점 MAE 18.7 / RMSE 21.8의 참사.
- **Q9.** 오차 자체의 무늬(차분에 남은 구조)를 기억하는 부품 —
  **ARIMA**(U5)의 AR·MA가 그것.
- **Q10.**

  | | 수준(α) | 추세(β) | 계절(γ) | 하루 앞 성적 |
  |---|---|---|---|---|
  | 기온 | 1.000 | 0 (죽음) | 0 (고정 파형, s=365) | 1.55 / 2.14 |
  | 지하철 | 0.342 | 0 (죽음) | 0.035 (s=7) | 43.5 / 79.0 |

## practice 추가 실습 정답

- **α=0.3 강제**: 기온 하루 앞 **2.02 / 2.65** — 최적(1.63)보다
  뚜렷이 나쁘다.
- **damped Holt**: 기온에서는 β=0이라 차이 없음.
- **마지막 주 반복(지하철 1년)**: MAE **77.7만 / 100.8만** — HW
  (54.1/89.5)가 확실히 낫다.
- **기온 HW 명암 월별**: 크게 번 달 12월(2.97 → 1.47), 11월
  (2.12 → 1.42), 10월(1.71 → 1.12), 1월(2.27 → 1.88) / 물어준
  달 3월(1.01 → 1.77), 4월(1.84 → 2.47), 5월(1.45 → 2.04) —
  고정 파형이 봄의 변덕을 못 따라간다.
- **HW 지하철 잔차**: |오차| 상위 10일 제외 시 MAE 35.0만.
  MAE/RMSE 비율 1.82(주간 naive 2.15) — 줄었지만 여전히 실패가
  몰려 있다.

## 완성 노트북 예시 설명

- 셀 구성: ① koreanize ② 로드+asfreq+분할 ③ SES fit+α ④ SES
  하루 앞 채점 ⑤ Holt fit+β ⑥ Holt 채점 ⑦ HW 지하철 fit+배합
  셋 ⑧ HW 지하철 채점 ⑨ 월별 비교표 ⑩ 최악 5일 ⑪ HW 기온
  fit+채점 ⑫ 기온 1년 예측 그림(실제+SES+HW) ⑬ 지하철 1년 예측
  그림 — 열세 셀.
- ③: 1.0.  ④: (1.63, 2.26).  ⑤: (1.0, 0.0).  ⑥: (1.68, 2.28).
- ⑦: (0.342, 0.0, 0.035).  ⑧: (43.5, 79.0).
- ⑪: (1.55, 2.14).
- ⑫: SES는 31.7도 수평선, HW는 계절 물결을 그린다.

## 수업 전 최종 확인

- ConvergenceWarning(기온 SES·Holt·HW)은 α가 경계 1.0에 붙어서
  나는 무해한 경고 — 수업 전에 한 번 만나 두고, 학생에게는 "경계
  가 곧 답인 경우의 투덜거림"으로 안내.
- HW(s=365)의 fit은 수 초 내로 끝난다(초기 계절 상태 365개를
  추정하지만 빠르다) — 멈춘 게 아님을 미리 언급할 필요는 없는
  수준.
- 6절 그림에서 forecast의 날짜 인덱스는 asfreq("D") 덕에
  자동으로 미래 날짜가 된다 — 2절 준비 셀의 asfreq를 건너뛴
  학생은 여기서 이상한 그림을 만나므로, 준비 셀 실행을 순회 중
  확인할 것.
