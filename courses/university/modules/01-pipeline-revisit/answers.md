# U1. 파이프라인 압축 재구축 — 정답 및 완성 예시

모든 수치는 data/의 두 CSV(2023-08-01 시작 1,096일) 기준.

## worksheet 정답

- **Q1.** 1,096일 / 1,096일, 2023-08-01 ~ 2026-07-31 — 같은 구간.
- **Q2.** 기온: 1년 주기의 매끈한 물결. 지하철: 주 단위의 빽빽한
  톱니 + 아래로 찍히는 바늘들(명절 급락).
- **Q3.** 기온 **11일, 전부 겨울**(최극단 2024-01-23, -12.3°C,
  z 2.3). 지하철 **37일, 전부 급락** — 설 연휴(2025-01-29 최소
  252만 등), 추석 연휴(2023-09-29, 2025-10-06 등), 1월 1일,
  공휴일 낀 일요일. 기온의 극단은 자연이, 지하철의 극단은 달력이
  만든다.
- **Q4.** 기온 월별 **-3.2 → 26.7**(O), 요일별 **12.6 →
  12.9**(평평). 지하철 월별 **647 → 753**(만 명, 완만), 요일별
  **447 → 798**(만 명, O — 일요일 최소·금요일 최대). 기온은
  **달**의 세계, 지하철은 **요일**의 세계.
- **Q5.** 기온 **0.98 / 0.92**, 지하철 **0.35 / 0.68**. 기온은
  시차 1(어제), 지하철은 시차 7(지난주 같은 요일) 쪽이 더 닮았다
  — 역전.
- **Q6.** (°C) naive **1.63 / 2.26**, 주간 naive **3.16 / 4.06**
  — **naive 승**.
- **Q7.** (만 명) naive **118.0 / 166.5**, 주간 naive **55.5 /
  119.1** — **주간 naive 승**. Q5의 예언 그대로: 자기상관이 큰
  시차를 베끼는 선수가 이긴다.
- **Q8.** **월요일, 299만** (화요일 41만의 일곱 배). 월요일의
  "어제"는 일요일 — 요일 프로필 월 733만 vs 일 447만, 286만
  차이를 naive가 매주 뒤집어쓴다. 토(195만)·일(155만)도 같은
  원리.
- **Q9.** 좋은 예측법은 **데이터의 성격**(리듬과 관성)이 정한다.
- **Q10.** **달력** — 그날이 명절·공휴일인지. 값의 과거만으로는
  부족하고 날짜의 의미가 재료로 필요하다(U7 예고).

## 수업 전 최종 확인

- 두 CSV의 URL 로드가 Colab에서 되는지 직전 확인(레포가 private
  이면 URL 로드가 안 된다 — 파일 업로드로 대체 안내).
- ⑨의 기온 월별 프로필은 **3년 전체** 기준(-3.2)이다. 고등
  과정 H7의 프로필(-2.2)과 숫자가 다른 이유는 그쪽이 훈련
  2년만 쓰기 때문 — 두 과정을 오가는 강의자는 헷갈리지 말 것.
  U1은 탐색 단계라 전체를 봐도 반칙이 아니고, 훈련만 쓰는
  규율은 모형을 만들기 시작하는 U2 이후에 적용한다.
- 지하철 값은 크다(백만 단위) — 만 명 단위 반올림을 워크시트
  코드가 해 주지만, 판서할 때도 "만 명"을 붙여 혼동을 막는다.
