## 3. 잰다 — 분포와 튀는 날

요약부터 — 읽는 법:

> `v.describe()`
> = 개수·평균·표준편차·최소·최대 등 요약 통계 한 벌

```python
t.describe().round(1)
```

```python
s.describe().round(0)
```

튀는 날은 z-점수로 찾는다. z-점수는 "평균에서 표준편차 몇 개만큼
떨어졌나"이고, 절댓값 2를 넘으면 상위 몇 %의 별난 날이다:

> `(v - v.mean()) / v.std()`
> = 각 값에서 평균을 빼고(거리) 표준편차로 나눈다(보폭) —
> 거리 ÷ 보폭 = 몇 걸음
>
> `z[abs(z) > 2]`
> = 절댓값이 2를 넘는 날만 골라라 (대괄호 안 조건 = 참인 행만)

```python
zt = (t - t.mean()) / t.std()
zt[abs(zt) > 2]
```

```python
zs = (s - s.mean()) / s.std()
zs[abs(zs) > 2]
```

## 6. 규칙과 심판 — 첫 채점

예측의 규칙을 선언한다. 이 과정 내내 유지되는 두 가지다:

- **홀드아웃**: 앞 2년(2025-07-31까지)만 보고 배우고, 마지막
  1년(2025-08-01부터)은 시험지로 봉인한다.
- **미래 금지**: 어떤 예측도 그 시점 이전의 정보만 쓴다.

심판은 둘 — 읽는 법:

> `e.abs().mean()`
> = 오차 절댓값의 평균 = **MAE** (평균적으로 몇 도/몇 명
> 틀렸나)
>
> `(e**2).mean() ** 0.5`
> = 오차 제곱 평균의 제곱근 = **RMSE** (큰 오차에 가중치를 주는
> 심판)

선수도 둘 — 가장 단순한 두 벽이다:

> `v.shift(1)`
> = 하루 밀기: 오늘 자리에 어제 값 → **naive** ("내일은 오늘과
> 같다")
>
> `v.shift(7)`
> = 7일 밀기 → **주간 naive** ("다음 주 그 요일은 지난주 그
> 요일과 같다")

기온부터:

```python
test_t = t["2025-08-01":]
e1 = test_t - t.shift(1)["2025-08-01":]
e7 = test_t - t.shift(7)["2025-08-01":]
print("naive   ", round(e1.abs().mean(), 2), round((e1**2).mean()**0.5, 2))
print("주간naive", round(e7.abs().mean(), 2), round((e7**2).mean()**0.5, 2))
```
