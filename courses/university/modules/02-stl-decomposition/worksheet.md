## 1. 세 성분의 언어

- **추세**(trend): 주기보다 느린 흐름 — 해가 갈수록 오르나,
  내리나.
- **계절**(seasonal): 정해진 주기로 반복되는 리듬 — U1에서
  프로필로 어림한 그것.
- **잔차**(residual): 추세와 계절을 걷어내고 남는 것.

기온 그래프(U1 Q2)에서 눈으로 짚으면: 1년짜리 물결이 **계절**,
물결의 중심이 흘러가는 선이 **추세**, 물결 둘레의 매일의 털이
**잔차**다.

## 2. 손으로 분해 — 원리 (기온)

계절부터 걷어낸다. U1의 프로필을 각 날짜 자리에 도로 뿌리는
도구가 transform이다 — 읽는 법:

> `t.groupby(t.index.month).transform("mean")`
> = 같은 월끼리 묶어 평균을 내되, 결과를 12줄 표가 아니라 **각
> 날짜 자리에 도로 뿌려라** — 8월 10일 자리에는 8월의 보통이 온다

```python
seasonal_hand = t.groupby(t.index.month).transform("mean")
dev = t - seasonal_hand
dev.plot(figsize=(10, 3), title="기온 - 월별 보통 (편차)")
```

이 뺄셈은 **잣대의 교체**다. 원본은 "0도 기준으로 몇 도"를
말하지만, 그 대부분은 그냥 계절이다. 빼고 남은 편차는 "**그
계절치고** 얼마나 특별한가"를 말한다 — 최저기온의 날
2024-01-23의 -12.3도는 1월의 보통(-3.2도)을 빼면 **-9.1도**,
"1월치고도 9도 낮은 날"이 된다. 한여름 27도는 8월의
보통(26.7도)을 빼면 +0.3 — 여름엔 흔한 날이다.

편차에서 느린 흐름을 건진다. 창을 밀며 평균 내는 도구가
rolling이다 — 읽는 법:

> `dev.rolling(window=365, center=True).mean()`
> = 각 날짜를 **중심으로**(center) 앞뒤 365일 창을 밀며 평균을
> 내라 — 1년 창이므로 계절의 오르내림은 상쇄되고 느린 흐름만
> 남는다

```python
trend_hand = dev.rolling(window=365, center=True).mean()
resid_hand = dev - trend_hand
trend_hand.plot(figsize=(10, 3), title="손 분해의 추세")
```

```python
round(trend_hand.min(), 2), round(trend_hand.max(), 2), round(resid_hand.std(), 1)
```

## 3. 기계로 분해 — STL (기온)

손 분해의 약점은 계절이 **월 계단**이라는 것이다 — 한 달 안에서는
같은 값이라, 월 안의 변화를 담지 못한다. 이 일을 정식으로 하는
기계가 **STL**이다(Seasonal-Trend decomposition using Loess —
이름의 Loess는 매끈한 곡선을 맞추는 방법, 유래는 teacher에게).

STL은 statsmodels에서 온다 — Colab에 기본 설치된 통계 모형
창고로, 이 과정 후반의 모형들(ETS·ARIMA)도 전부 여기서 온다.
오늘이 첫인사다. 읽는 법:

> `STL(t, period=365)`
> = t를 주기 365일로 분해할 준비를 하라
>
> `.fit()`
> = 실제로 쪼개라 — 결과에 `.trend` `.seasonal` `.resid` 세
> 성분이 담긴다
>
> `.plot();`
> = 관측·추세·계절·잔차 네 층 그림을 한 번에 — 줄 끝의
> 세미콜론은 "결과값 출력은 생략"이다. 빼면 같은 그림이 두 번
> 나온다(고장 아님 — 그림 객체가 결과값으로 한 번 더 표시되는
> 것)

```python
from statsmodels.tsa.seasonal import STL

stl_t = STL(t, period=365).fit()
stl_t.plot();
```

```python
round(stl_t.trend.std(), 1), round(stl_t.seasonal.std(), 1), round(stl_t.resid.std(), 1)
```

## 6. 잔차는 백지인가 — 다음 모듈로 가는 다리

분해가 다 설명했다면 잔차는 아무 구조 없는 **백지**(어제와
오늘이 무관한 잡음)여야 한다. U1의 도구로 확인하자:

```python
round(stl_t.resid.autocorr(1), 2), round(stl_s.resid.autocorr(1), 2)
```

지하철 잔차: ______ (원본 0.35).

지하철 잔차는 거의 백지가 됐다. 그런데 기온 잔차는 계절을
걷어냈는데도 어제와 오늘이 여전히 꽤 닮았다 — 계절이 아닌
**며칠짜리 관성**(따뜻한 주간, 추운 주간)이 남아 있는 것이다.

잔차에 구조가 남아 있다 = **아직 예측할 것이 남아 있다.** 이
남은 구조를 어휘로 읽는 법(U3), 모형으로 잡는 법(U4·U5)이
다음 세 모듈이다. 잔차가 백지가 될 때까지 — 그것이 모형의
일이다.
