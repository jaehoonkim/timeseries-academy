막혔던 지점과 답을 여기 남긴다. 가치 있는 것은 해당 모듈 teacher.md
"예상 질문"으로 옮긴다.

- **U1** Q8 "가장 아픈 요일"이 안 읽힘 — '아프다'는 선수 은유를
  고등 과정에서 가져왔는데, 대학은 독립 과정이라 첫 등장인데도
  병기가 없었음(H6 '미스'·H7 '벌었는지' 건과 같은 유형) — 저작
  원칙(압축 은유는 첫 등장에 용어 병기)이 과정 경계에서 리셋된다는
  교훈 → "가장 아픈 요일 — 오차가 가장 큰 요일 —"로 병기.
  → worksheet 반영됨.
- **U2** 2절 "계절을 걷어낸다 = 그 달의 보통을 뺀다"의 의미가
  선언만 있고 다리가 없음 — 빼기가 왜 계절 제거인지, 남은 편차가
  무엇을 말하는지 구체 사례 부재(H4는 다리가 있었으나 과정
  독립이라 U에선 첫 등장, 패턴 16 유형) → dev 셀 뒤에 "잣대의
  교체" 문단 추가(-12.3도 → 1월치고 -9.1도, 한여름 27도 → +0.3).
  → worksheet 반영됨.
- **U2** 2절 `trend_hand.min().round(2)`가 Colab에서 에러 —
  실측: Colab(pandas 2.2.3)의 `min()`은 맨 파이썬 float를
  반환(`type()` 확인), `mean()` 계열은 .round 가능 타입이라 같은
  버릇의 U1 코드는 통과했던 것. 로컬은 pandas 2.2.3/3.0.5 어느
  조합으로도 재현 불가 — Colab 환경 특이로 결론. 교훈: 스칼라
  반올림은 내장 `round(x, n)`만 쓸 것(로컬 실행 검증이 Colab을
  보증하지 않는다, 잣대 패턴 17) → U1 네 줄·U2 세 줄 교체,
  Series의 `.round()`는 유지, 고등·중등은 패턴 자체 없음 확인.
  → worksheet(U1·U2) 반영됨.
- **U2** 3절 "Loess = 매끈한 곡선을 맞추는 방법"에서 강의자가
  Loess의 정체를 물음 — teacher 심화의 세 줄 요약("국소 가중
  회귀")이 설명 재료로 얇았음 → rolling 평균과의 비교
  다리(평균=수평선 vs 작은 회귀선, 균등 가중 vs 거리 가중)와
  "손 분해 두 부품을 Loess로 바꾸고 반복시킨 정식판 = Q4 잔차
  반감의 이유"까지 심화 보강. → teacher 반영됨.
- **U2** 3절 `stl_t.plot();`의 세미콜론이 설명 없이 첫 등장(패턴
  2) — 빼고 실행하면 그림이 두 번 나와 "잘못했나" 싶은 지점
