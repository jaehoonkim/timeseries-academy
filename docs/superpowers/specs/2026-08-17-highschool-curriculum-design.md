# 고등학생 시계열 데이터 분석 커리큘럼 — 설계 문서

- 날짜: 2026-08-17
- 상태: 승인 대기
- 선행 경험: 중학생 과정(courses/middle) 제작·학습 완료가 설계 입력

## 목적

강의자가 스스로 학습·실습한 자료를 그대로 고등학생 대상 강의 교안으로
사용하는 모듈형 커리큘럼. 중학생 과정과 같은 통합 모듈형(4파일 구조)을
유지하되, 대상과 도구·깊이를 고등학생에 맞춘다.

## 확정된 요구사항

| 항목 | 결정 |
|---|---|
| 과정 전제 | **독립 과정** — 중등 이수를 전제하지 않음. 겹치는 기초는 파이썬으로 압축 재도입 |
| 실습 도구 | **파이썬 전면** (Colab + pandas, 1모듈부터) |
| 심화 상한 | 분해·자기상관(ACF)·지수평활까지 정식으로 + **특징 기반 회귀 예측**. ARIMA·본격 ML은 심화 소개만 |
| 교안 형식 | 중등과 동일한 마크다운 4파일 (teacher / worksheet / practice / answers) |
| 실습 데이터 | 서울 일별 기온 3년 (data/ 공유), H8만 각자 데이터 |
| 수학 연결 | 고교 수학(통계: 표준편차·상관계수, 함수) 범위를 적극 활용하되 넘지 않음 |

## 중학생 과정 경험에서 가져오는 원칙

제작 과정에서 확립되어 그대로 적용하는 규칙:

1. **토론 가이드 내장** — 생각해 보기 질문마다 출제 의도·기대 답·오답별 되묻기.
2. **"읽는 법" 형식** — 새 함수·문법은 첫 등장 때 코드 앞에서 조각별로 분해 설명.
3. **데이터 기준 선언** — 실습 시작 상태(원본 CSV·이전 모듈 산출물)를 서두에 명시.
4. **모든 정답 수치는 실제 데이터로 검증** — 가상 수치 금지.
5. **용어는 유래를 다리로** — 이름부터 던지지 않고 대표 사례에서 이름으로.
6. **음성 결과도 발견** — "패턴 없음", "무승부"를 의도된 학습 재료로 배치.
7. **정답 미리 보기 금지** — 예측 실습은 홀드아웃과 shift를 처음부터 규칙으로.

## 커리큘럼 (8모듈)

각 모듈은 75분(고교 50분 2교시 연강이면 넉넉) 1회 분량, 독립 조합 가능.
전 모듈이 서울 기온 데이터를 사용하고 H8에서만 각자 데이터로 확장한다.

| # | 제목 | 핵심 내용 | 중등과의 관계 |
|---|---|---|---|
| H1 | 시계열과 파이썬 | 시계열 정의, Colab/pandas, 날짜 인덱스, 그래프, 날짜 조회 | M1+M6+M7 앞부분의 압축 재도입 |
| H2 | 분포로 보는 시계열 | 평균·중앙값·**표준편차**, 히스토그램·상자그림, z-점수 이상치 탐지, 오타 vs 사건 | M2의 심화 (고교 통계 연결) |
| H3 | 평활 — 이동평균과 지수평활 | rolling(후행/중심), **ewm(지수평활)**, 창·α 트레이드오프 | M3의 심화 |
| H4 | 계절성과 분해 | 계절성 프로필, 편차(anomaly), **관측 = 추세+계절+잔차 손 분해** | M4의 심화 |
| H5 | 자기상관 | 상관계수(고교 확통), lag plot, shift·corr, **ACF 읽기**, naive가 강한 이유 | 신규 |
| H6 | 예측과 평가 | naive·계절 naive·이동평균·지수평활 대결, 홀드아웃, **MAE·RMSE** | M5의 심화 |
| H7 | 회귀로 예측 | 특징 만들기(월·요일·lag), 선형회귀, 시간 순서 분할, 벤치마크 이기기 | 신규 |
| H8 | 미니 프로젝트 | 각자 데이터 수집 → 분석 → 예측 → 발표 (H1~H7 총동원) | M8과 동형 |

서사 축: **본다(H1) → 분포로 잰다(H2) → 매끈하게 편다(H3) → 쪼갠다(H4)
→ 어제와 오늘의 관계를 잰다(H5) → 예측하고 평가한다(H6~H7) → 내 데이터로(H8)**.

H5(자기상관)가 이 과정의 허리다: H2의 상관계수를 시간축으로 확장해
H6~H7의 "왜 이 방법이 이기는가"를 설명하는 언어가 된다.
