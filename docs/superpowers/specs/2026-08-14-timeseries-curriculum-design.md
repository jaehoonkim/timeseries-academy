# 중학생 시계열 데이터 분석 입문 커리큘럼 — 설계 문서

- 날짜: 2026-08-14
- 상태: 승인 대기
- 접근 방식: 통합 모듈형 (A안)

## 목적

강의자(개발 + 데이터 기초 보유)가 시계열 분석 입문 내용을 스스로 학습·실습한 뒤,
그 자료를 그대로 중학생 대상 강의 교안으로 사용할 수 있는 모듈형 커리큘럼을 만든다.
학습 자료와 교안을 하나로 통합해 내용 불일치를 원천 차단한다.

## 확정된 요구사항

| 항목 | 결정 |
|---|---|
| 강의자 배경 | 개발자, pandas·통계 기초 있음 |
| 강의 형태 | 미정 → 독립 조합 가능한 모듈형으로 대응 |
| 실습 도구 | 1부 구글 스프레드시트 → 2부 파이썬(Colab + pandas) |
| 교안 형식 | 마크다운 문서 세트 (슬라이드는 범위 밖) |
| 실습 데이터 | 기상청 서울 일별 기온 (실제 공공데이터, 최근 3년) |

## 커리큘럼 (8모듈)

각 모듈은 60~90분 수업 1회 분량이며 독립적으로 조합 가능하다.
전 모듈이 동일한 서울 기온 데이터를 사용하고, M8에서만 각자 데이터로 확장한다.

### 1부 — 스프레드시트로 개념 잡기

| # | 제목 | 핵심 내용 | 실습 |
|---|---|---|---|
| M1 | 시간이 담긴 데이터 | 시계열 정의, 꺾은선 그래프 읽기·그리기 | 기온 데이터 입력 → 그래프 |
| M2 | 평균의 힘과 함정 | 평균·중앙값, 이상치의 왜곡 | 이상치 넣고 빼며 비교 |
| M3 | 추세 찾기 — 이동평균 | 잡음 속 추세를 이동평균으로 드러내기 | 7일 이동평균 수식 계산 → 겹쳐 그리기 |
| M4 | 반복되는 패턴 — 계절성 | 월별/요일별 패턴, 피벗 테이블 맛보기 | 월평균으로 계절성 확인 |
| M5 | 첫 예측 | 단순 예측(naive, 이동평균)과 오차 비교 | 예측 대회 형식 |

### 2부 — 파이썬으로 확장 (선택)

1부만으로도 커리큘럼이 완결되며, 2부는 코딩 확장이다.

| # | 제목 | 핵심 내용 |
|---|---|---|
| M6 | 파이썬으로 다시 보기 | Colab 시작, pandas로 CSV 읽기, M1~M3 재현 |
| M7 | pandas 시계열 도구 | 날짜 인덱스, resample, rolling, 결측치 처리 |
| M8 | 미니 프로젝트 | 각자 데이터 수집 → 분석 → 예측 → 발표 |

## 디렉토리 구조

```
ts/
├── README.md                  # 저장소 개요, 과정 목록
├── data/                      # 과정 간 공유 실습 데이터
│   ├── seoul-temp-daily.csv   # 공통 실습 데이터
│   └── README.md              # 출처, 갱신 방법
├── courses/
│   └── middle/                # 중학생 과정 (본 스펙의 범위)
│       ├── README.md          # 과정 개요, 진행 방법, 모듈 조합 가이드, M8용 데이터 후보
│       ├── PROGRESS.md        # 강의자 학습 체크리스트
│       └── modules/
│           ├── 01-time-data/
│           │   ├── teacher.md         # 강의자 노트
│           │   ├── worksheet.md       # 학생 배포용 (정답 없음, 인쇄 가능 수준)
│           │   ├── practice.md        # 강의자 사전 학습 과제
│           │   └── answers.md         # 정답 + 완성 예시
│           ├── 02-averages/ … 05-forecasting/   # 동일 4파일 구조
│           ├── 06-python-intro/ … 08-mini-project/
│           │   └── (+ notebook.ipynb) # 파이썬 모듈만: 학생용 빈칸 노트북
└── docs/superpowers/specs/
```

`courses/<level>/` 한 단계는 미래 방향(아래) 대비이며, 이 스펙의 구현 범위는 `courses/middle/` 뿐이다.

### 파일별 역할

- **teacher.md**: 분 단위 수업 흐름, 개념 설명 대본, 예상 질문/오개념 대응,
  강의자용 심화(예: M3 이동평균 창 크기 트레이드오프, M5 naive forecast가
  실무 베이스라인인 이유). 심화는 강의자 수준(개발+데이터 기초)에 맞춘다.
- **worksheet.md**: 학생 활동 안내 + 빈칸/질문. 중학교 수학 범위 밖 개념은
  설명 없이 등장하지 않는다.
- **practice.md**: 강의자가 강의 전 학습자 입장으로 수행할 실습.
- **answers.md**: worksheet·practice 정답, 완성 그래프 설명, 파이썬 모듈은 정답 코드.

## 진행 방식 (모듈당 사이클)

1. Claude가 모듈 4개 파일 작성
2. 강의자가 practice.md를 학습자 입장으로 직접 수행
3. 막힌 지점을 질문 → 설명 후, 가치 있는 질문은 teacher.md "예상 질문"에 반영
4. 소화 완료 확인 → PROGRESS.md 체크 → 다음 모듈

제작 순서: 기반(README, PROGRESS, 데이터) → M1 → … → M8. 한 번에 한 모듈씩.

## 검증 기준

- 실습 데이터는 실제 다운로드 가능한 공공데이터로 확인 (가상 데이터 금지)
- 파이썬 노트북 코드는 전달 전 실제 실행으로 동작 확인
- worksheet는 중학교 수학 과정 준수 셀프 체크
- 모듈 문서 4종의 내용 일치 (worksheet 활동 ↔ answers 정답 ↔ teacher 흐름)

## 미래 방향 (이 스펙의 범위 아님)

대상별 과정을 단계적으로 확장한다: 중학생(본 스펙) → 고등학생 → 대학생 → 직장인.
각 과정은 시작 시점에 별도 스펙으로 설계하며, 중학생 과정의 제작·강의 경험을
상위 과정 설계의 입력으로 삼는다. 공유 데이터(`data/`)와 `courses/<level>/`
구조 외에 지금 미리 만드는 것은 없다.
