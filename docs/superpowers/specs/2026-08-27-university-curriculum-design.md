# 대학생 시계열 데이터 분석 커리큘럼 — 설계 문서

- 날짜: 2026-08-27
- 상태: 승인됨 (2026-08-27)
- 선행 경험: 중학생·고등학생 과정(courses/middle, courses/high)
  제작·학습 완료가 설계 입력

## 목적

강의자가 스스로 학습·실습한 자료를 그대로 대학생 대상 강의 교안으로
사용하는 모듈형 커리큘럼. 3단계 과정의 마지막 층 — 고등 과정이
멈춘 지점에서 출발한다. 고등에서 ARIMA·ML은 강의자 심화(teacher)
에서 **이름만 소개**됐고 학생 자료에는 등장하지 않았으므로, 이
과정의 모형들은 학생에게 전부 신규다. 고전 시계열 모형을
정식으로 다루고, 특징 기반 ML과 대결시킨다.

## 확정된 요구사항

| 항목 | 결정 |
|---|---|
| 과정 전제 | **독립 과정** — 중등·고등 이수를 전제하지 않음. 겹치는 기초는 U1에서 압축 재도입 |
| 대상·수학 | **전공 무관 교양** — 고교 수학 + 대학 1학년 기초통계 수준까지만 본문 활용. 행렬·미적분 유도는 강의자 심화로 |
| 심화 상한 | **고전 시계열 정식 + ML 도전** — STL·ACF/PACF·정상성·ETS(Holt-Winters)·ARIMA/SARIMA·예측 구간을 정식으로, 특징 기반 부스팅으로 대결. 딥러닝은 심화 소개만 |
| 실습 도구 | 파이썬 전면 (Colab + pandas). **statsmodels·scikit-learn 정식 채용** — 둘 다 Colab 기본 제공. 추가 설치 라이브러리 금지 |
| 교안 형식 | 동일한 마크다운 5파일 (slides / teacher / worksheet / practice / answers), slides는 강의자 소화 후 작성 |

| 분량 | 8모듈 × 1회(90분 기준), 독립 조합 가능. U8은 2회차 권장 |

## 앞선 과정 경험에서 가져오는 원칙

중등에서 확립되고 고등에서 검증·확장된 규칙을 그대로 적용한다:

1. 토론 가이드 내장 — 질문마다 의도·기대 답·오답 되묻기.
2. "읽는 법" 형식 — 새 함수·문법은 첫 등장 때 조각별 분해.
3. 데이터 기준 선언 — 실습 시작 상태를 서두에 명시.
4. 모든 정답 수치는 실데이터로 검증 — 가상 수치 금지.
5. 용어는 유래를 다리로 — 이름부터 던지지 않는다.
6. 음성 결과도 발견 — "무승부"·"판단 불가"를 학습 재료로.
7. 정답 미리 보기 금지 — 홀드아웃·shift를 처음부터 규칙으로.
8. (고등에서 추가) 압축 은유는 첫 등장에 정확한 용어 병기,
   출력의 모양(배열·칸 순서)까지 설명, 벤치마크(naive의 벽)부터
   채점, 질문 기록 루틴으로 환류.
9. (고등 H8에서 검증) **결론이 데이터 따라 뒤집히는 장치** —
   같은 방법이 데이터의 성격(자기상관·주기)에 따라 이기고 지는
   경험을 본편에 내장한다. 이번 과정은 두 데이터를 정식으로 써서
   이 장치를 상시 가동한다.

## 커리큘럼 (8모듈)

각 모듈은 90분 1회 분량, 독립 조합 가능. 기온(연 주기, 자기상관
0.98)과 수요 데이터(주 주기, 달력 효과)를 대조군으로 쓴다.

| # | 제목 | 핵심 내용 | 앞 과정과의 관계 |
|---|---|---|---|
| U1 | 파이프라인 압축 재구축 | 두 데이터 탐색, 프로필·편차, naive의 벽, 홀드아웃·MAE/RMSE — 한 바퀴를 90분에 | 고등 H1~H6 핵심의 압축 재도입 |
| U2 | 분해 정식 — STL | 손 분해의 자동화, 추세/계절/잔차, 잔차가 남긴 정보, 두 데이터의 분해 대조 | H4의 정식화 (statsmodels 첫 등장) |
| U3 | 시계열의 어휘 — ACF·PACF와 정상성 | ACF 복습, PACF, 정상성 개념, 차분이라는 처방, 두 데이터의 상관 구조 대조 | H5의 확장 + 신규(PACF·정상성) |
| U4 | 지수평활 가족 — ETS | SES → Holt(추세) → Holt-Winters(계절), 배합 서사의 정식 모형화 | H3 ewm의 정식화 |
| U5 | ARIMA | AR·MA의 뜻, 차수 고르기(ACF/PACF + AIC), 적합과 잔차 진단 | H7 회귀 서사의 고전 모형 연장 |
| U6 | SARIMA와 예측 구간 | 계절 차수(기온 s=연? 수요 s=7), 점 예측에서 구간 예측으로 — 불확실성을 말하는 법 | 신규 |
| U7 | 특징 기반 ML 도전 | lag·달력·rolling 특징, 부스팅 트리, rolling-origin 교차검증, 고전 모형과의 대결 — 데이터마다 승자가 다르다 | H7의 확장 + 신규(교차검증) |
| U8 | 파이널 프로젝트 | 각자 데이터로 전 과정 + 모형 대결 + 구간 예측, 발표 | M8·H8과 동형 |

서사 축: **벽을 다시 세운다(U1) → 쪼개서 듣는다(U2) → 어휘를
갖춘다(U3) → 고전의 대가들(U4~U6) → 도전자 ML(U7) → 내
데이터로(U8)**.

U3(어휘)가 이 과정의 허리다: ACF/PACF·정상성이 U4~U6 모형
선택의 언어이자 U7 특징 설계의 근거가 된다 — 고등 과정에서
H5가 했던 역할의 정식판.

두 데이터의 역할 분담: 기온은 관성·연 주기의 세계(ETS·ARIMA가
강한 무대), 수요 데이터는 달력의 세계(요일·공휴일 특징을 쥔
ML이 강한 무대). U7의 대결에서 승자가 데이터마다 갈리는 것이
과정 전체의 결론 문장이 된다.

## 진행 방식

앞선 과정과 동일: 설계 승인 → 기반(README·PROGRESS·둘째 데이터

## 검증 기준

- 모든 코드는 실행 검증, 정답 수치는 data/의 CSV 기준.
- worksheet 본문은 교양 수준 준수 — 모형은 "무엇을 배합하는가"의
  언어로 설명하고, 수식 유도(우도·상태공간)는 강의자 심화로.
- 5파일 내용 일치, 워크시트 검토 잣대(맥락 결함 15패턴) 적용.
- 라이브러리는 Colab 기본 제공(pandas, matplotlib, statsmodels,
  scikit-learn)만. 부스팅은 sklearn HistGradientBoosting 사용 —
  추가 설치 없음.
- 둘째 데이터는 출처·라이선스(공공데이터)와 갱신 절차를 data/
  README에 기록.
